# Skill 使用与编辑设计预览

打开 [index.html](index.html) 查看交互设计。页面与 SVG 均使用本地资源，支持直接打开；也可在仓库根目录运行 `python3 -m http.server 18641 --bind 127.0.0.1`，访问 `http://127.0.0.1:18641/app/design-previews/skill-use/`。

本目录是独立交互样例，示例编辑仅保存于本页内存，刷新后恢复，不改写本机技能文件。生产页面的技能标签／卡片采用 S01，入口与添加操作按用户最新要求恢复为底部工具栏的手形图标，并接入结构化引用、通用文件预览编辑、修订保护保存、Skills／MCP 批量选择与统一重载应用；实际约束以 `docs/design.md` 为准，`ui/` 原始设计未修改。

## 交互约定

### 技能与 MCP 列表

沿用当前深色表面、选项、搜索和来源说明。每项 Skill 提供两个独立的 44px 操作入口：技能图标“用于本次消息”、铅笔“编辑 SKILL.md”。按钮不嵌套在勾选 label 中，避免触发误选。

以下为原交互样例的行为：勾选表示本会话可用技能；首次执行后锁定成员。使用按钮将已选择且可用的 Skill 添加到本条消息草稿，不触发发送，不直接执行技能。生产实现现已采用下述全量加载及自动发现选择方案，样例中的未选禁用提示不再代表生产行为。资源不可用时禁用使用与编辑，并显示原因。MCP 不增加 Skill 使用／编辑按钮。

### 输入框上方

展示紧凑标签：技能图标、名称、Skill 标记、移除按钮。相同技能按稳定文件身份去重；多个标签换行。再次点击已有技能反馈“已添加”。移除标签不取消会话选择。添加后聚焦原输入框，保留正文与附件；手机将输入区滚动到可见位置。

标签只代表“本次消息指定的技能”。发送前可以编辑任务文本；空任务提示补充描述。发送后，技能信息随用户消息保留为可展开卡片，标签从草稿区移除。真实实现必须按主／子会话隔离草稿，保留发送失败和结果未确认的原始请求数据；运行中的追加沿用 Steering 队列。

### 会话卡片

默认收起，显示同一 Skill 图标、技能名和“本条消息指定的技能”，采用现有8px圆角与细边框。展开显示发送时简介、来源路径、版本信息和“编辑当前技能文件”。文件修改后旧消息继续保留发送时快照，编辑入口始终指向当前文件。原版本与当前文件应明确区分。

“文件已读取”是单独的状态设计，仅在有真实读取结果且关联到该技能文件身份时出现。添加、发送受理、目录发现和环境列表都不能当作读取或成功执行的证据。预览中的读取状态仅为静态样例。

### 编辑 SKILL.md

可从列表铅笔或会话卡片进入。编辑器显示技能名、文件路径、完整 Markdown、未保存状态、取消与保存。关闭／Escape／取消遇到草稿时，显示“继续编辑／放弃修改”；保存只在内容变化时启用。原消息不因保存而改写，已在执行的 Agent 不宣称即时应用新内容。

预览用示例正文演示编辑；实际接入需要以下契约：

- 读取／保存必须用能力目录的稳定技能身份，服务端重新校验工作空间、会话归属及允许的目标 `SKILL.md`，不可接受任意路径写入。
- 显示实际路径与可写性。应用托管、只读、失效文件按实际权限禁用保存并说明原因。
- 读取返回文件修订；保存携带原修订，冲突保留用户草稿并提供重新读取／比较入口，不覆盖外部修改。保存原子化并校验技能元数据。
- 历史卡片保留发送时名称、简介、来源和内容摘要；“编辑当前文件”不暗示能编辑历史快照。
- 保存后刷新能力元数据；后续执行按已有资源身份规则重新加载。已有执行不被打断，也不声称已热更新。

## 验证

Chrome 浏览器的14项检查全部通过，覆盖50个图标与筛选、图标联动、技能去重／移除、发送与选择锁定、卡片展开、编辑保存、取消／Escape未保存保护及历史版本保留；控制台、页面异常与资源错误均为0。

1440×1000、820×1180、390×844、360×800、390×480均无页面横向溢出，50个候选可达，短屏编辑器可内部滚动。桌面／平板修复后的发送与技能移除按钮已复核为44×44px；三个手机视口此前即为44×44px。未验证实体手机软键盘或真实Agent／文件读写。

截图与报告在 [测试产物目录](../../test-results/skill-use-design/)；最终报告为 `interaction-final.json` 与 `report-final.json`，初轮报告保留修复前的事实。

## 接入边界

生产代码已贯穿草稿持久化、发送、Steering、历史展示与技能指南读取。手动使用复用 pi 原生 `/skill:name` 展开函数，宿主只保留身份映射、多选组合和显示元数据；列表显示名称与简述，简述最多两行并省略溢出，来源路径与待重载状态收入名称悬停提示，避免额外文字行撑高条目。全部有效技能进入内部列表，勾选只控制自动发现索引，未勾选仍可手动引用或使用原生 `/skill:name`；属性仅在会话运行时设置，不修改共享文件。面板默认打开排在前面的「当前会话」，「全局默认」在后；主会话的 Skills 与 MCP 均先暂存多项选择，跨标签、搜索、关闭再打开、切换会话及本窗口刷新保留草稿，点击“应用并重新加载”才一次生效；“重置选择”恢复已确认状态。统一按钮复用左下角完整重载及成功页面刷新流程，运行中等整批工具完成后重载并续接，空闲重载不请求模型。等待时标注待应用且禁止重复提交，失败保留草稿，外部更新冲突要求重置后重新选择。当前会话应用不改全局默认；全局应用成功后同事务保存偏好并应用到当前会话。其他窗口在成功前仍展示已确认选择，子任务不能单独调整能力范围。MCP 支持新增、移除与同名配置热加载，连接异步建立，重载完成不等于全部连接成功。输入区使用紧凑标签并与附件共享换行区域，消息区保留两行卡片。技能编辑通过通用文件预览按发现的技能 ID 授权，使用 UTF-8、文件修订与元数据校验保存；历史消息保留发送时信息。添加引用或目录发现不代表实际读取成功。

本页仍是内存模拟交互，不调用生产接口；生产行为与验证见 `docs/design.md`、`docs/ui-sync.md`。
