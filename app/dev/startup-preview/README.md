# 启动页浏览器模拟测试

复用 `desktop/main.tsx` → 真实 `Connect` 页面；独立开发入口，不进入正式桌面配置。

```sh
cd /Volumes/D_Work/axiom2/app
node_modules/.bin/vite --config dev/startup-preview/vite.config.ts
```

打开 http://127.0.0.1:5198/ 。选择顶部场景会重载并重置内存状态；刷新也可重新测试。停止：终端 Ctrl-C。配置只监听 loopback、独立缓存，不代理任何后台。

## 可以测试

- 后台服务、桌面客户端、运行时与 SDK、远程连接均直接使用内置 `ComponentCard`，不再使用独立的启动页卡片或其皮肤。运行时详情里的 Node.js、npm、应用内 Pi 也使用内置环境子组件。
- 组件使用原生的名称旁图标操作、当前/最新版本及折叠说明；可测明暗主题、移动宽度、键盘展开和 Escape 收起。任务、错误和已打开确认不随说明隐藏。
- Node/npm 缺失→模拟准备环境→模拟安装后台，启动/停止及停止确认。
- 更新、终端 Pi 的确认和进度；HTTP 403、安装失败、中断核实、状态未知禁写。
- 客户端复用现有 `MaintenanceTaskView`：下载递增、403 失败后重试、精确任务取消、取消失败、回执不完整时核实，保留历史任务。
- macOS 下载完成后待手动安装、模拟打开下载位置；Windows 下载 MSI 后另行确认安装。下载不改变当前客户端版本、不自动安装。
- 旧桥无内置下载能力时保留发布页外链，并由预览拦截；缺少本平台附件时禁止提交。

顶部共 24 个场景，含 Mac/Windows 缓存旧包不会遮住新版下载入口。新增原生桥/更新器代码尚需打包后的原生验收；此网页仍使用内存模拟，不能证明真实 Mac/Windows 下载或中断恢复通过。
- 远程连接失败、迟到响应及切换设备。

所有 IPC 写操作仅修改内存。顶部始终显示模拟标识；外部链接/新窗口被拦截，CSP 限制网络为本测试源。未知 IPC 抛错，绝不回退至真实桥接。可展开“说明与调用记录”查看调用。

## 不代表通过

没有真实安装、卸载、更新、启停后台、连接远程设备或打开 MSI。组件清理不模拟，相关操作明确拒绝；不复制系统目录或运行命令。浏览器测试不能验证原生权限、网络下载、签名/校验、双 WebView、系统安装器或升级后的文件与进程。
