- [ ] 产物/运行版本、最小分析或观察器能力已证

- [ ] 具体步骤/命令已静态检查，无import时顶层模型副作用
- [ ] metadata零网络预检与真实auth/network分开；必要baseline已保存，活动资源归属清楚
- [ ] cwd/安装版loader/ESM入口、raw配置、继承执行绑定与fixture路由已核，真实全工具集已序列化
- [ ] 实发harness/源码/依赖/产物与已通过自测的指纹匹配；仅导入无副作用，失败后不复用claim，快照不复制新预算

- [ ] 对普通离线测试：隔离目录/端口与结果文件，不改被测源码；修复后可重验受影响范围
