字段与接口约定

以下是建议的自有后台接口，不是 OpenAI 官方接口。服务端负责平台适配、鉴权和密钥保管。

  • 有数据展示真实值；数值 0 是有效数据，不使用真假判断隐藏。
  • 不支持capabilities 对应项为 false，跳过查询并收起模块；全部无额度能力时改为订阅说明。
  • 未返回能力存在但 data 为 null，核心额度显示“暂未返回额度”；等级显示“未返回等级”；其他字段省略。
  • 加载中首次显示“查询中”；再次查询保留上次成功值，并标注正在更新。
  • 查询失败仅在失败模块显示原因和重试。已有数据保留并标注“上次数据”，不伪装成当前值。
  • 订阅进度仅订阅账号且 usage 返回有效百分比时展示进度，左侧剩余比例，右侧周期及重置时间。无订阅或无周期数据则不占位。余额独立显示，不混算百分比。
  • 点数精度高精度点数与金额支持十进制字符串，原样保留小数位。点数、美元与周期百分比互不换算。
  • 周期与费用usage.windows 支持多个周期；仅有百分比也可展示，不要求总点数。费用估算独立标注来源，金额未返回显示“—”，不从额度推算。有效期按后台提供的时区展示；无时区时保留原值。
  • 认证与健康默认账号来自身份接口；已保存认证不代表当前有效；账号检查结果与模块查询状态分别展示。过期判断由后台返回，前端不依据样本日期伪造状态。
  • 健康状态绿色“监控中”仅表示 auth 成功返回可用；黄色为未确认；红色为封禁、停用、认证过期或检查未通过。额度查询超时不等于封禁。
  • 扩展与复用统一模块状态与卡片渲染。presentation.fields 通过 module 与 path 绑定对应 GET 接口；position 为 above（进度条上方）或 below（下方，兼容旧配置默认值），missing 为 hide 或 dash。两区按内容宽度排列，每行最多三个、无边框；标题和内容均不换行，超长内容可聚焦后横向滚动查看。标题可选配 Lucide 小图标，icon 为空或省略时不显示；点击供应商图标可编辑位置、标题、图标、字段、颜色与操作个数。
  • 卡片操作默认依次刷新、删除；删除需二次确认，生产模式调用 DELETE /api/accounts/{id}，失败保留卡片。自定义操作触发 account-card-action 事件（accountId、actionId），由宿主绑定后台行为；不会执行任意脚本或 URL。

账号列表：GET /api/accounts 返回 id、provider、type、label 与 capabilities。列表失败时保留原列表并提供重试。

卡片区域查询接口 · GET关键字段

路径中的 {id} 是内部账号 ID。各模块独立加载，不因一个失败清空其他模块。401 / 403 提示重新授权，429 按 Retry-After 重试；不要在前端调用平台私有接口或保存密钥。

所有模块使用相同信封；模块内的 data 按右侧接口映射定义。页面源代码包含同协议的查询适配点。

{
  "status": "success",
  "data": {
    "remaining": 84.2,
    "total": 120,
    "unit": "USD",
    "unlimited": false
  },
  "updatedAt": "2026-04-08T09:30:00Z"
}
// 未返回数据
{ "status": "empty", "data": null }

// 平台不支持，也可由 capabilities 提前声明
{ "status": "unsupported", "data": null }

// 单模块错误，不清空其他模块
{ "status": "error", "data": null,
  "error": { "code": "TIMEOUT", "message": "查询超时" } }

loading / idle 由客户端管理。失败时缓存的旧值不属于新的成功响应；需保留旧时间并标记过期。金额与数量必须是非负有限数或非负十进制字符串；高精度值建议返回字符串。可选字段缺失时省略，不以 0 补齐。日期应返回带时区的 ISO 8601；历史无时区样本保留原文。

添加演示账号

创建一张本地卡片，查看缺少后台数据时的展示效果。

不收集 API Key；不保存真实凭据。新增内容仅保留于当前页面，刷新后重置。真实账号连接需对接服务端。

编辑卡片

配置当前账号的供应商、标记、操作和信息块。名称可在卡片上双击修改。

特殊标记

套餐、默认状态随接口更新；自定义标记可选择颜色。

操作按钮

按列表顺序展示，默认先刷新、后删除。按钮较多时可横向滚动；删除始终需要确认。

信息展示块

每块按“上标题、下内容”展示，标题左侧可选择小图标，也可不显示；按内容宽度排列，每行最多三个、无边框；标题和内容不换行，超长内容可聚焦后横向滚动查看；可选择放在进度条上方或下方。绑定查询模块与字段路径，例如 windows.0.remaining；未支持时隐藏，缺失值可隐藏或显示“—”。

当前为本地演示。卡片配置、名称修改和删除仅在当前页面生效，不修改真实供应商账号。

删除账号卡片？

仅移除管理列表中的卡片，不注销供应商账号。演示页面刷新后恢复。
