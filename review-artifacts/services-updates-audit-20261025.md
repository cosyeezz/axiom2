复制图标尚未点击：只读审查证实现有剪贴板 guard 不能保证多格式保真或并发安全，需独立 Windows 会话验证，不能冒险覆盖用户内容。当前可安全执行的有限原生分支及 R4 交付验证已完成；R4 同任务取消/延时有真实受理及清理回执，完整进程重启后两组预算保留并恢复原值，最终 ZIP 独立解压/哈希核验通过。验收用 R4 实例均已正常退出，正式客户端和用户旧测试窗口保持不动。

## 已修复

1. **Windows 安装被普通 npm 日志中断**：Windows PowerShell 5.1 的 `2>&1 | ForEach-Object` 将正常 stderr 转为终止错误。改为直接运行受监督的 Node，保留 stdout/stderr 日志和真实退出码。用真实 PowerShell 与临时假 Node 复现并回归，未真正安装 npm 包。
2. **中断的后台安装无安全恢复出口**：新增“核实退出回执并解除占用”。原生侧持注册锁及原任务 owner.lock；只接受 Windows `installing` 阶段，核对原任务、owner、request、ready、cleaned 身份及完整的树退出/父退出回执。先持久化失败终态再释放占用；缺证据或可能已启动后台时拒绝。不是按 PID 消失推断退出，也不直接删除锁。
3. **Pi 验证失败后被检查/刷新抹掉重装资格**：独立持久化未完成验证标记；失败、取消及其他任务不能清除，只有完整运行验证成功后解除。覆盖了 npm 已开始但 package.json 仍是旧版本的取消场景。
4. **Pi 入口/包装器目录冒充文件**：安装前健康检查及安装后验证统一核实文件类型。POSIX 符号链接核对目标和执行位。Windows 尚未对任意 `.cmd` 内容做完整的实际终端调用验收。
5. **下载好的客户端安装器被 Pi 任务覆盖**：独立 SQLite 记录就绪 artifact，兼容旧 ready job 迁移。检查、刷新、进程重建、新版本下载失败均不丢失；每次交原生启动前重新核实类型、链接数、大小及 SHA，损坏记录不覆盖无关任务。
6. **已升级后仍显示旧 MSI 入口**：客户端版本等于或高于 artifact 时不提供常规“运行安装器”入口；保留文件记录，以免用户取消安装时误丢失。
7. **Windows 删除限制提示过晚**：Pi、托管后台、下载归档的首屏增加平台限制说明。保留安全拒绝，不冒充已实现 Windows 安全删除。
8. **离线维护打包依赖解析失败**：构建脚本从 `app/package.json` 所在位置解析已有 esbuild，兼容只安装 app 依赖的工作区，不新增安装依赖。生成的独立宿主已用 plain Node 实际启动，核实读取成功、删除请求拒绝且文件树未变、超大输入拒绝。
9. **浏览器回归陈旧**：明确维护区入口、设备 option 容器和工作台按钮；短视口允许合理纵向滚动，仍核实横向溢出、菜单边界、布局和可达性。mock 的 Pi 检查/刷新真实替换当前任务，避免掩盖跨任务缺陷。
10. **Pi 未安装却预览失败**：仅确实缺包返回 `installed:false/token:null`，正常展示保留清单且没有删除确认；残留/损坏/legacy/npm 错误仍拒绝。Windows 隔离后端 28 过、8 skip；真实 helper、浏览器和新原生空预览分别有独立证据。
11. **真实首屏宿主无响应**：把原生 resize/page-load 回调中的同步布局改为非主线程排队、合并请求和相同 bounds 跳过，缓存锁不跨原生调用。独立 R2 首屏、真实主题/历史与 Win32 缩放最小化后保持响应；工作台切换、换屏 DPI、关闭竞争未完整验证，不将静态假设写成已证调用链。
12. **空后台记录误报不安全读取**：安全 open 的 `NotFound` 改为“本地后台尚未安装”，权限/目录/超大等拒绝保持；Windows standalone Rust 3 项通过，新原生首屏提示已目视确认。
13. **Windows 缓存原子替换过早失败及取消缓存覆盖**：新增 atomic helper，仅 win32 rename 的 EBUSY/EPERM 最多7次/6次退避，绝不先删目标/改权限，使用独占本次tmp；取消可中断并保留原缓存/repair资格，清理不遮主错。EPERM也可能是永久权限，不能假称已精确定位AV。22项新增回归、相关55过8 Windows skip、真实Windows FS6项通过；R4原生取消有真正受理、cancelled及stopped/writerStopped/nonce回执，延时同ID1200→1201秒后成功。
14. **新增模块运行依赖遗漏**：R3虽然编译成功，但独立闭包审查发现atomic模块未发布，未运行该包。补template拷贝和Rust资源清单，资源回归修前1过2失败、修后3过，R4闭包与真实启动均通过。
15. **原生拒绝消息被控件丢失**：Tauri字符串拒绝转为Error，原Error身份不变、参数不改、不重放；原生缺失Pi路径现在可显示具体拒绝。
