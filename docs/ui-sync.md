## 同步流程

1. 用户提供的设计更新单独提交，不混入实现变更。
2. 阅读变更页面、样式、脚本和图片，确认入口与交互。
3. 在开发代码中移植差异，保留真实服务接入和隔离边界，不整目录覆盖 `app/`。
4. 对照设计检查响应式布局、交互和视觉效果。
5. 完成验收后替换本页的采用提交与状态；部分完成则保持采用提交不变，并仅记录当前待完成项。

文件一致性检查不替代浏览器验收。设计检查脚本执行前需在开发副本中审查，不修改设计源来适配测试。本页只保留当前有效信息，不累积同步日志。
