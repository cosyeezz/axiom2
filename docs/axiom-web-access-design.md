# Axiom 专用联网能力实施方案

> 状态：**方案定稿，待实施**。定稿日期：2026-10-27。
>
> 本文是后续联网能力开发的范围与验收依据，不代表工具已注册、浏览器已接入、MCP 已授权或真实搜索已验证。本轮只落方案文档，不修改业务代码、不安装组件、不启动浏览器、不访问账号或执行查询。
>
> 子代理机制正在改造。本文只规定联网能力包的对接契约，不接管其调度、持久化、模型继承或卡片改造。通用机制见[子代理类型机制设计](subagent-types-design.md)，其中未定的通用协议仍由该方案收敛。
>
> 早期选型、价格与候选对比保留在[网络访问研究](axiom-web-access-research.md)和[主流 Agent 实现对比](mainstream-agent-web-access.md)。涉及首期范围、Google 默认来源、工具命名和启用方式时，**以本文为准**，不把早期候选清单当成默认启用清单。

## 1. 已确认的设计决策

| 事项 | 定稿决策 |
| --- | --- |
| 运行环境 | 同一电脑上的 Axiom 后台、专用浏览器与用户授权的常用 Chrome；本期不做远程浏览器或无桌面服务器方案 |
| 公共搜索 | Google 为主，不做百度适配，不默认增加其他搜索 API／搜索 MCP |
| 能力归属 | 新增联网工具只装配给专用联网子代理；主 Agent 负责委派、追问、读取与整合交付 |
| 工具形式 | 结构化原生快捷工具，后台程序负责浏览器操作、抓取和解析，不让模型拼 shell 或清洗 stdout |
| Google 热路径 | 原生工具直接调用后台 Google 适配器与受控浏览器，去掉每次调用 CLI 的包装 |
| 其他站点 | 保留 YouTube、小红书等站点能力；首期可使用 OpenCLI／Bridge 兼容后端，不重写所有适配器 |
| 浏览器身份 | Google 匿名专用浏览器与常用 Chrome 登录态分开，不复制或导出 Cookie |
| 网络出口 | Google 绑定指定内置代理线路；其他请求执行显式路由策略，不暗改系统或常用浏览器代理 |
| Skills 与 MCP | Skill 指导工作流；MCP 按服务及具体工具授权；安装、启用、连接和实际调用分开记录 |
| 模型处理 | 不在每个搜索／读取工具内部再隐藏调用摘要模型；由联网子代理统一判断和综合 |
| 结果协议 | 工具输出统一来源、证据和错误；任务交付沿用子代理既有结果链路，不另建完成通知协议 |

**不在本期范围**：默认引入付费搜索、绕过验证码或访问控制、自动登录、任意站点写操作、通用浏览器编程工具、全站抓取平台、向量库／RAG、音视频 ASR，以及 OS 级网络沙箱重构。

## 2. 分层架构与职责

```text
主 Agent
  │ 任务目标、范围、授权内的能力选择
  ▼
专用联网子代理
  ├─ 原生工具：web_search / web_read / 精选站点只读快捷工具
  ├─ Skills：检索策略、核验、引用、站点工作流
  └─ MCP：明确选中的服务和具体工具
          │ 结构化请求 + 任务身份 + 取消信号
          ▼
Axiom 后台联网服务 WebRuntime
  ├─ GoogleAdapter ── 专用 Chrome / CDP ── 指定内置代理
  ├─ HttpReader ───── 受控 HTTP ── 本地正文提取
  ├─ SiteAdapter ──── OpenCLI / Browser Bridge ── 授权常用 profile
  └─ McpAdapter ───── 受控 MCP 客户端 ── 独立认证及路由
          │
          ▼
结构化来源与证据 → 子代理核验和综合 → 主 Agent 整合
```

- **主 Agent**：不直接获得这批新增搜索、网页和站点工具；提供自包含任务，接收带来源的结论。短查询也沿用该边界，不为追求速度再开一条绕过路径。
- **联网子代理**：规划查询、选择来源、交叉核验、形成结论；不管理代理凭据、浏览器安装或任意 MCP 配置。
- **工具层**：校验参数，附加可信执行身份，返回可消费内容；不承担通用 shell、另一个模型代理或完整浏览器自动化平台的职责。
- **后台服务**：执行请求，管理路由、浏览器租约、并发、预算、提取、缓存和证据。

WebRuntime 是服务边界，不要求固定为独立 OS 进程。可在后台内实现或使用受监督进程；需要 IPC 时保留结构化协议，不以“零 JSON 转换”为目标牺牲身份校验与故障隔离。

## 3. 与子代理改造的对接契约

文中用 `web-research` 指代**专用联网角色**。最终注册 ID 与正在改造的类型机制对齐；这不替代通用研究／测试类型，也不确认其尚未定稿的参数或模型继承方案。

联网能力包提供：

1. 类型用途说明、检索规则和交付要求；保留 Axiom／Pi 基础提示词与通用阶段约束。
2. 原生工具工厂及具体调用策略；首期默认不授予任意 shell、外部扩展、递归委派或任意文件写入。
3. 允许选择的 Skills、MCP 服务和 exact tool 集合；不继承父会话全部资源。
4. 浏览器通道、站点授权、网络路由和预算策略。
5. 能力定义修订及实际选中资源身份，用于准入、重载和 worker 复用校验。

通用子代理机制负责保存并传递任务类型与获准选择，联网侧消费解析后的能力快照。模型只能选择授权目录标识，不能传入扩展路径、可执行代码、MCP URL／command／env／headers 或代理凭据。

- 若支持动态选择：候选发现 → 模型选择 → 宿主验证 → 保存获准集合 → 装配；展示候选不安装或连接服务。
- 追加、重载和恢复不自动扩权；能力失效明确失败，不自动换角色、服务或出口。
- 同一策略生成工具声明、激活集合和实际调用守卫；间接调用也校验最终工具。
- 总结／停止阶段继续禁止工具；工具晚注册或 MCP 重连不能重新打开权限。
- 角色、授权、资源修订、浏览器身份和路由变化参与执行环境身份或等效失效检查，不能复用串权 worker。
- 最终模型选择、任务卡片、通知与 `read_result` 使用通用机制；本文不另设模型配置、状态树或结果读取入口。

## 4. 原生工具契约

模型侧固定使用 `web_search` 和 `web_read`。早期研究中的 `web_fetch` 是概念命名，不要求注册重复工具或兼容一个尚不存在的旧接口。具体 TypeBox 定义在实施时由同一契约生成并测试。

### 4.1 web_search

语义：在 Google 找来源，默认只返回搜索结果，不自动读取全部落地页，也不生成另一份 AI 答案。

| 输入 | 约定 |
| --- | --- |
| `queries` | 非空查询数组；每项含 `query`，可含 `language`、`region` 偏好 |
| `limit` | 每条查询最多返回的有效结果数；后台去重后严格限量 |

批量查询是减少模型往返的主要入口。数组长度、查询长度、结果数及总响应体积均由服务端设置有限上限；参数 schema、工具描述和执行检查必须一致。地区／语言是偏好，不等于实际代理出口位置，结果记录实际执行信息。

- 搜索来源固定为 Google，不提供模型可随意切换的 provider 字段。
- 返回标题、来源、摘要及结果类型；保留实际 query 与抓取时间。无敏感参数时可直接提供来源 URL；否则只返回脱敏展示值和 `targetRef`，完整地址由后台保存，不把删参后的展示值当成等价访问地址。
- featured snippet／PAA 等若没有可靠 URL，可作为线索返回，但不得伪造链接或作为已核实来源引用。
- 无结果、同意页、验证码、DOM 不匹配和网络失败分别分类，不能全部当成空结果。
- 若后台只封装 `spawn opencli`，必须标记为兼容实现，**不能计为 Google 去 CLI 热路径验收通过**。

### 4.2 web_read

语义：读取选定来源，返回有边界的正文及证据定位。首期普通网页使用受控 HTTP；动态页面与登录态不进行无感升级。

| 输入形态 | 约定 |
| --- | --- |
| 新读取公开地址 | `urls` 为非空 URL 数组；可提供 `maxChars` 作为单项返回字符预算 |
| 新读取已登记目标 | `targetRefs` 为非空的不透明目标引用数组；后台解析完整 URL 后执行读取；可提供 `maxChars` |
| 续读既有正文 | 使用已有 `sourceId` 与不透明 `cursor`；可提供 `maxChars` |

三种形态互斥；未知字段、无效组合及超上限输入明确拒绝。`maxChars` 不能放宽下载字节、解析内存或任务总预算。

`targetRef` 表示**可尝试读取的目标**，与表示**已经取得的证据快照**的 `sourceId` 不同。搜索／站点适配器将完整地址保留在后台，向模型提供绑定工作空间、任务及授权范围的引用。解析时重新检查授权、站点、路由及 URL 安全，不以持有引用代替许可；引用失效时明确诊断，不要求模型重建令牌。首次抓取结果生成独立 `sourceId`，后续只用其 cursor 续读同一正文快照。

- 支持受控批量，各项独立返回状态；单项失败不抹掉其他有效证据。
- 默认处理文本与 HTML；PDF、图片、附件和媒体不是自动支持范围，不支持时明确返回原因。
- 需要 JS、登录或特殊站点能力时返回诊断及可用的授权入口，不自动改走常用 profile 或云 Reader。
- 续读绑定同一证据快照，不重新请求后拼接成貌似连续的正文；cursor 不接受任意本地路径。
- 默认不下载图片、不保存到工作目录、不调用 OpenCLI 的整套文章导出流水线。证据落盘由宿主管理。

### 4.3 站点快捷工具

按使用频率增加明确的只读动作，例如视频信息、可用字幕、笔记正文或评论读取；名称和参数在对应站点适配时确定，不首期铺满目录。

工具直接调用 SiteAdapter／受控 MCP 客户端，不让模型重新拼 CLI。内部暂用 OpenCLI 时采用固定命令与参数数组，不经 shell 字符串解释，复用其受管运行环境。

字幕只表示确实取得的字幕，不等于对任意视频做 ASR 或视听理解。需要完整带令牌 URL 的站点不得删参后声称等价访问；URL 本身可能敏感，应受控保存与脱敏展示。

## 5. 输出、证据与交付

统一工具封装至少包含：`schemaVersion`、`requestId`、总体 `status`、逐项 `items` 及必要的 `warnings`。请求身份由宿主生成并关联任务／运行，不信任模型自报归属。

| 状态 | 含义 |
| --- | --- |
| `success` | 请求正常完成；按约定限量或分页不属于失败 |
| `empty` | 正常执行但没有有效结果，不包括验证码或连接失败 |
| `partial` | 已有有效输出，但其他子项失败或期限中断影响了目标结果 |
| `error` | 没有可交付的有效输出，附逐项错误与是否可恢复 |

批量结果保留每个输入的归属、状态、来源或错误；全批正常无结果为 `empty`，全批失败为 `error`。单次读取中断只取得部分正文时标为不完整证据，不当成全文成功。

每份可引用证据至少记录：

- `sourceId`：宿主管理的证据快照标识，关联任务、请求和授权范围。
- 标题、查询归属、采集时间，以及服务端保存的完整请求／最终 URL。模型只接收安全的 `displayUrl` 和可用时的公开引用 URL；敏感目标另返回 `targetRef`，不输出完整令牌地址。若无等价的公开引用地址，展示脱敏来源与 `sourceId`，不伪造可点击链接。
- 实际 backend／搜索来源及不含凭据的路由身份。
- 证据类型：搜索摘要、网页正文或站点记录；不得把 snippet 标成已读全文。
- 正文／必要摘录与位置、分页截断标记、内容完整性及已知限制。

模型可见内容提供有预算的正文／摘录、来源和状态；机器字段使用结构化结果，不把同一长正文在文本和 JSON 中重复堆给模型。Pi 的 `structuredContent` 不意味着模型不再需要可读 `content`。

联网子代理按通用任务协议交付结论、对应来源、核验范围和局限。长证据由宿主保存并可授权回查，不为此新增另一套任务完成协议、卡片或计费来源。

## 6. 双浏览器通道

### 6.1 Google 匿名专用通道

- 使用独立、非日常数据目录的 Chrome 实例，不登录 Google 账号，不接管默认浏览器目录。
- 目标是后台执行且不激活常用窗口；headless 是否采用，以兼容与授权验收结果确定，不能把 daemon 等同于无浏览器。
- CDP 只监听本机；精确绑定本次创建／租用的 target，不依赖启发式选中用户页面。
- 浏览器由后台复用，不由每个子代理任务反复冷启动。任务只持有目标和请求租约。
- 初期浏览器仅用于受控 Google 检索流程；任意动态网页渲染不是默认能力。

### 6.2 常用 Chrome 登录通道

- 通过 Browser Bridge 连接用户明确授权的常用 profile，沿用其已有登录态及网络。
- 多 profile 时明确选择，不猜账号；不读取／导出 Cookie、密码或浏览器数据库。
- 只允许授权站点与预审过的读取流程，不暴露任意 JS、任意 URL 导航或提交操作。
- 不暗改该 profile 的代理。不能承诺“仅改变某个标签代理，不影响同 profile”。
- 若用户将来要求登录站点也走内置线路，须另行确认网络影响，或选择独立持久 profile 并由用户手动登录；不作为本期自动行为。

OpenCLI 的 `OPENCLI_CDP_ENDPOINT` 如用于兼容执行，只能按调用／子进程注入 Google 通道，不能全局覆盖常用 Bridge。

## 7. 代理与认证

复用 Axiom 已有 Xray／mihomo 内置线路，不增加第二套订阅、节点或系统代理管理。界面可沿用“模型代理”入口，但新浏览器与工具流量必须显式接线，不能假设模型代理环境自然生效。

| 请求 | 路由及认证约束 |
| --- | --- |
| Google Chrome 导航 | 绑定选定线路标识，由后台解析实际本机入口并完成浏览器代理认证 |
| 普通 HTTP 正文抓取 | 使用独立、显式 dispatcher；与任务获准的公开网络路由一致，不使用模型全局 dispatcher 猜测出口 |
| CDP／Browser Bridge 本机控制 | 固定的本机内部连接，不经公网代理；不开放为任意 loopback 请求能力 |
| 登录站点页面流量 | 沿常用 profile 原有网络；不由 Node 的代理变量代替 Chrome 配置 |
| MCP | 按该服务明确的 transport／认证／路由配置执行，OAuth 与刷新路径也需核验，不自动继承 Chrome 登录或模型线路 |

内置代理入口包含动态端口、认证令牌及 generation，均留在服务端私有运行态。模型／通用日志／工具结果不接收带凭据的代理 URL，命令行也不承载令牌。

Chrome 不使用 `--proxy-server` 中内嵌的账号密码。实施时须选择并验证受控本机转接或 CDP 代理认证方案；若使用 CDP，必须区分 Proxy 与 Server challenge，覆盖新 target，不能把代理凭据发给网站。

线路停止、重启、切换或 generation 变化时撤销旧绑定并重新准入。不能继续使用失效入口，也不静默直连、切节点或换搜索 provider。既有证据保留其历史来源，不能因切线伪装为新抓取。

## 8. HTTP 抓取与正文提取

- 网络下载与正文提取分离：受控 HTTP → 内容类型识别 → 本地提取 → 规范化文本／Markdown → 分页证据。
- 网络层分别限制重定向、响应头等待、无数据等待、总期限、压缩前后字节、正文长度和解析资源。具体数值见实施参数表，不用字符上限代替字节限制。
- 只允许 HTTP(S)，拒绝 URL 用户信息、非授权端口及不允许的地址；逐跳校验重定向和实际连接目标。
- 不允许以 `web_read` 访问 loopback、私网、链路本地、元数据地址等内部资源。固定 Bridge／CDP 控制连接不构成例外给模型使用。
- DNS 预解析不足以防 rebinding；直接连接应绑定已验证地址并保留正确 TLS／Host 语义。经代理远端解析时，须证明有等效的目标约束／出口 ACL；不能做到时，拒绝该模式下任意 URL 抓取，而不是宣称已完成强 SSRF 防护。
- Defuddle／Readability 等本地提取器沿用已有研究和 fixture 进行选型，不在本文擅定未经回归的依赖版本。关闭异步补抓、远程补全及隐式图片下载。
- 提取器不是 HTML 消毒或网络安全层；前端不直接执行提取结果中的脚本或未经处理的 HTML。

浏览器还会发起子资源、跳转等请求，单独校验初始 URL 不等于浏览器出网隔离。任意动态网页回退在请求级限制验证前不开放；常用登录浏览器按授权站点环境使用，不宣称是隔离沙箱。

## 9. Skills 与 MCP

### 9.1 Skills

联网 Skill 描述查询分解、优先原始资料、跨源核验、引用标准、站点限制和失败处理。它引用真实注册工具及参数，不再把 OpenCLI CLI 教程作为常用检索前置步骤。

Skill 是指引和资源，不产生执行权限，也不是文件访问 ACL。网页、Skill 或 MCP 返回中的指令不能扩大宿主授权。

### 9.2 MCP

- 本期不默认增加 Exa／Parallel／Brave 等搜索服务；保留精选平台能力的接入点。
- 只装配任务明确选中的服务，并对具体工具授权；默认隐藏或不注册未获准工具，实际调用仍做最终守卫。
- 常用小集合可 direct；首期不以通用 codemode／tool_search 作为默认入口。以后开放间接调用时，必须先验证其子调用、资源 URI 和最终工具权限。
- `readOnlyHint` 为服务端声明，不是权限证明。工具列表变化不自动扩大授权。
- deferred／codemode 主要影响暴露方式，不代表服务按需连接。连接行为由宿主明确控制，候选展示不建连。
- API MCP 的 OAuth／Key 独立管理；登录、刷新、撤销和连接状态不能仅因有配置文件就视为完成。
- 自有常用原生能力不为内部复用再绕一层 MCP → CLI；仅在未来对外提供统一客户端接口时另议 MCP 暴露。

## 10. 生命周期、权限与缓存

- 请求携带可信 task／run／request 身份及有效能力快照；不向模型开放底层可执行入口、任意文件路径或认证材料。
- 总期限不晚于任务工作截止；取消贯穿队列、HTTP、导航、等待、解析与证据提交。超时 race 不等于底层动作已停止。
- 取消后拒绝迟到结果污染本次交付；保留可诊断状态。清理失败或进程硬停止时，后台依据归属与租约回收，不仅依赖 JS shutdown 钩子。
- 共享浏览器按 profile、认证范围和路由身份隔离；任务停止只释放自身 target／租约，不能杀用户浏览器、Bridge daemon 或其他任务。
- 浏览器状态不确定时先隔离／销毁本任务目标，不立即复用污染会话；搜索与站点请求设置有界并发及排队，禁止同一 page 并发导航。
- 公共与登录态缓存分开；缓存键至少覆盖请求、来源后端、授权范围、profile、路由及适配器修订，不把私人正文复用于匿名任务。
- 缓存命中也校验授权并标记采集时间；性能缓存与历史证据保留分开管理，证据不可被后续刷新悄悄改写。
- 查询、私有页面、带令牌 URL 和正文可能敏感；日志最小化，文件私有权限，不默认遥测或上传云提取。
- 不执行发布、评论、点赞、关注、私信、上传、下载或账号设置修改。读取可能产生浏览计数等站点副作用，不能宣传“零副作用”。

只把新增联网工具交给专用角色，是**能力装配边界**；现有主／子代理 shell 可能出网，工具白名单、提示词和独立 HOME 都不是 OS 安全沙箱。若以后要求其他进程绝对不能联网，应独立设计网络隔离。

## 11. 组件管理与依赖复用

- 沿用[内置组件独立环境](builtin-component-environments.md)及[模型代理](model-proxy.md)的维护、版本、取消和卸载边界，不改系统 PATH、全局 npm 或其他工具环境。
- Google 原生路径不以 OpenCLI CLI 为执行前置；若复用其公开模块，则由实现明确绑定运行时、版本和许可证，不能暗中从全局安装取包。
- 常用站点兼容路径复用受管 OpenCLI 和指定 profile；组件未安装、版本不兼容或 Bridge 未连接时明确诊断，不隐式安装或切到用户全局 CLI。
- 新的原生核心不要求额外 sidecar；兼容执行仍可 spawn 锁版 OpenCLI，必须如实计入冷启动和初始化开销。
- 浏览器可执行程序的来源、支持版本、许可与检查流程在实施阶段选择。不能把开发依赖 Playwright 当作发行版已有浏览器运行时，也不默认随包捆绑大型浏览器。
- 安装不等于启用，启用不等于授权账号，配置存在不等于连接成功。组件卸载需核对在途请求与归属，不删除常用 Chrome profile。

研究核验的是本机 OpenCLI **2.0.2**：公开 `browser/cdp`、`browser/page` 等构件，但没有完整的“加载并执行内置 Google adapter”SDK；包根入口是 CLI，不能直接 import 当库。公开导入边界也不等于长期兼容保证，须封装并锁版回归。

OpenCLI 为 Apache-2.0，合规复用源码需保留许可证／归属并标记修改，依赖另核；不修改 `node_modules` 作为持久实现，不深导入内部执行器冒充公开 SDK。当前全局安装版本不等于 Axiom 托管安装的实际版本。

## 12. 实施拆分与现有接入位置

以下是职责划分，不是已经新增的模块或固定文件名：

| 工作包 | 交付 | 接入边界 |

| WebContracts | 参数、状态、错误与来源契约，有限预算策略 | 共享类型与工具 schema 同源，不包含服务端密钥 |
| WebRuntime | 请求调度、路由绑定、取消、租约、证据与缓存 | 宿主服务／受监督运行实例 |

| HttpReader | 受控下载、本地提取、分页和 SSRF 约束 | 明确 dispatcher，不借模型全局网络 |
| SiteAdapter | 只读站点快捷工具与 OpenCLI／Bridge 兼容 | 固定动作和参数，不开放通用命令 |
| 联网能力包 | 专属规则、工具工厂、Skills／MCP 选择及调用策略 | 改造后的子代理注册／资源装配机制 |
| 管理与诊断 | 组件、路由、profile、连接与授权状态 | 复用内置工具入口，不另建调度或计费 |

Pi 核验版本为 **1.1.0**，可用公开自定义工具／宿主扩展入口实现。实施前按 [pi-development 技能](../app/skills/pi-development/SKILL.md)重新定位实际依赖并完整阅读相关文档、示例；优先公开 API。`noExtensions` 与宿主可信工具装配不是同一概念，不为此全局放开外部扩展。

## 13. 实施顺序与交付门槛

| 阶段 | 范围 | 完成依据 |
| --- | --- | --- |
| A：契约与核心 | 工具契约、WebRuntime、假后端、证据／错误／取消、本地 HTTP 提取 | 离线 fixture 验证有界输入输出、路由与授权不串用、取消及分页正确 |
| B：Google 原生 | 专用浏览器托管、代理认证、CDP 精确 target、Google 搜索和热路径复用 | 无 CLI 的执行证据；代理失败不直连；经授权完成真实 Google smoke，明确验证码与地区差异 |
| C：专用子代理接入及登录兼容 | 接入通用子代理改造，加载能力包；保留授权 Bridge 站点入口与统一诊断 | 主代理仅委派；普通类型不扩权；续跑／重载／恢复不串权；停止不关闭用户浏览器；经授权验证选定登录站点 |
| D：按需增强 | 高频站点逐个原生化、精选平台 MCP、质量与缓存优化 | 每项独立权限／路由／许可审查与回归，不自动扩展首期默认清单 |

A—C 为首期交付目标，D 不作为首期必须接入的服务清单。后台核心、离线 fixture 可与子代理改造并行；端到端角色装配依赖通用改造提供第 3 节契约，不能用临时全局扩权代替。

实施和真实站点验收需另行启动；缺组件、线路、浏览器授权或外部条件时记录阻塞，不用假后端通过代替生产链路完成。

## 14. 验收清单

### 14.1 功能与契约

- `web_search`、`web_read` 的批量、上限、无效参数、逐项归属与部分失败行为明确且一致。
- Google 普通结果、featured／PAA、空结果、同意页、验证码和 DOM 变化有离线 fixture；无可靠 URL 不伪造引用。
- 原生搜索不 spawn CLI；登录兼容路径如实标识后端，不声称全部去 CLI。
- HTML、纯文本、代码、表格、相对链接、重定向、超大／压缩响应和不支持类型有回归证据。
- 正文分页不混快照，搜索摘要与全文证据可区分，截断和部分读取如实标记。

### 14.2 权限与安全

- 普通角色不获得新增联网工具；伪造未声明工具、跨站点、跨服务及间接调用均被拒绝。
- MCP 工具动态变化、能力失效、总结阶段晚注册、追加／恢复／worker 复用不扩权。
- 内部 URL、地址变体、重定向、DNS 变化、代理远端解析及浏览器请求边界按实际支持模式验证；未验证的任意浏览器抓取不开启。
- Google 代理停线／切代／认证失败不直连；本机控制链路不外送；OAuth 刷新路由有实际证据。
- 宿主不主动向模型或通用日志回传账号凭据、Cookie、代理令牌及 URL 敏感参数；目标引用不能跨任务／越权使用，脱敏 URL 不被误当完整地址。用户已在输入中提供敏感 URL 时，不宣称模型此前不可见；不误改系统及常用 profile 网络。

### 14.3 取消、恢复与兼容

- 排队、导航、抓取、解析和 MCP 调用期间取消，均无迟到提交或无限后台动作。
- 浏览器／worker 异常退出、硬停止、代理重启和 Bridge 断开后可诊断、可回收；不误杀共享实例。
- 阶段切换、追加、资源重载、后台重启恢复保持同一角色与获准集合，并重新验证失效资源。
- 现有任务结果、通知、精确读取、普通研究／测试、受管组件和模型网络边界不回归。

### 14.4 性能与真实站点

分别记录排队、子代理首请求、工具派发、冷／暖浏览器、导航、解析、返回与综合耗时，以及模型轮次、token／费用和失败率。同条件比较 CLI 兼容与原生路径，不只比较 JSON 转换耗时。

专用子代理增加委派及模型开销，单次短查询未必更快；收益还包括主上下文隔离与研究并行。无实测不写倍数、免费无限额度或风控成功率。

离线测试与真实站点 smoke 分开报告，记录实际命令、退出码、范围、产物和未验证项。真实浏览器／账号／节点／收费服务均须获相应授权，不把文档定稿当执行授权。

## 15. 实施前须补齐的选择与风险

这些是实施细节与发布门槛，不改变已确认的架构，也不表示本轮已验证：

| 项目 | 后续必须确定／验证 |
| --- | --- |
| 子代理接入 | 与在改机制对齐最终类型 ID、能力选择及执行身份；不在本文件另定通用模型／卡片协议 |
| 浏览器托管 | 可执行程序来源、支持平台／版本、后台或 headless 模式、目录权限、端口与崩溃回收 |
| 代理认证 | 选定受控转接或 CDP 接线，验证所有 target、认证 challenge、停线及切代 |
| 预算参数 | 批量大小、结果数、字节与字符、超时、并发、队列、缓存 TTL／容量、证据保留策略；不得发布无限默认值 |
| 提取器与依赖 | 固定版本、技术文档质量、生产依赖可用性、包体与许可证；不能沿用实验版本而不复核 |
| 站点适配 | 首批实际站点／动作、授权 profile、返回内容、失效处理和平台条款；不承诺所有视频有字幕 |
| MCP | 精选服务与 exact tools、认证及撤销流程、连接时机、调用和刷新路由；无选择不默认启用 |
| SSRF 与隐私 | 实际连接约束、代理解析边界、浏览器限制、敏感 URL／正文保留及脱敏；达不到强保证的模式必须受限 |
| 外部稳定性 | Google DOM／地区差异／验证码、Bridge／Chrome 版本变化；不以隐式换源掩盖故障 |
