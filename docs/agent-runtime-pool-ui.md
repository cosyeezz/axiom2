# 运行池管理 UI 草案

**状态：界面与交互建议，尚未实现。** 本文配套[代理运行池统一方案](agent-runtime-pool-design.md)；已确认的生命周期不再另开架构选项。入口、布局、参数初值是本轮建议，不表示现有产品已有此面板，也不授予代码实施、强杀、真实模型/MCP 或部署权限。

## 1. 信息架构

### 1.1 应用级入口

建议在工作台侧栏底部、“配置”入口上方增加 **运行池 · N**，打开应用级非模态抽屉；会话环境中补“绑定实例／查看运行池”关联入口。配置页可以跳到同一配置区域，不建设第二份独立设置。

现有[工作台侧栏](../app/src/client/pages/Workbench.tsx)集中放工作空间、会话历史和配置；[会话环境](../app/src/client/chat/SessionState.tsx)则按业务会话隔离。面板应位于会话 keyed 子树之外，切换会话不卸载归还/恢复状态。侧栏收起时保留可访问入口；窄屏从现有导航入口打开全宽面板，不占据永久聊天宽度。

打开/刷新/筛选池面板只读取状态，不创建业务会话、不补热、不连接 MCP、不发模型请求。关闭面板或切换页面不取消已受理的归还/续跑；重开可恢复操作进度。

### 1.2 页面分区

1. **总览**：全部存活数、最大保活数、互斥状态计数、超量说明、同步状态。
2. **实例列表**：工作空间/状态筛选，实例及绑定详情，安全归还操作。
3. **会话恢复记录**：归还结果、暂停与重试、自动续跑进度；不依赖实例仍绑定原会话。
4. **保活设置**：仅三个配置及规则说明。

## 2. 桌面示意

以下为静态示例，`8 / 10 分钟 / 15 分钟`均为建议初值；示例只列部分行，不据可见行推算总数。

```text
运行池                                                   [关闭]
全部存活 10    最大保活 8    超出 2 · 暂无空闲超时的销毁候选
运行 4  会话空闲 2  池中空闲 2  预热 1  归还中 1

工作空间 [全部 v]   状态 [全部 v]   搜索 [实例ID / 会话名称]
显示匹配项 / 全部 10                         状态已同步

实例       工作空间  绑定会话       状态       连续空闲    操作
#A17       项目 A    修复导出       运行中     —           [归还…]
#A18       项目 A    调整布局       会话空闲   6 分钟      [归还池中]
#A19       项目 A    未绑定         池中空闲   5 分钟      —
#B20       项目 B    未绑定         预热中     —           —
#B21       项目 B    整理资源       等待安全点 —           查看进度

会话恢复记录
校对文案   已暂停 · 实例已归还          [重试] [打开会话]
整理资源   等待安全点 · 将自动续跑       查看详情

保活设置
最大保活个数             [ 8  ] 个
会话空闲回收时间         [ 10 ] 分钟
实例空闲回收时间         [ 15 ] 分钟                 [保存]
全部实例超出保活数，且池中实例空闲超时，才会销毁符合条件的实例。
```

恢复记录按会话显示当前有效操作；示例中已暂停的“校对文案”没有绑定实例，不计入实例行或存活总数。同一会话不能同时显示“当前运行”与“同代操作已暂停”。

## 3. 总数、状态与筛选

### 3.1 不使用容量进度条

标题使用“**全部存活 N · 最大保活 M**”，不用“已用 N/M”“剩余名额”或满格进度条，避免把保活目标误读为硬并发上限。

全部数包括预热中已创建、绑定准备中、运行中、会话空闲绑定、池中空闲、归还中、刷新/隔离及销毁中的尚存实例；销毁确认后才移除。尚未创建的准备任务另列“等待准备”，不计入存活数。

| 数量关系 | 提示文案建议 |
| --- | --- |
| `N <= M` | 当前在保活目标内；池实例仅因空闲超时不会被销毁 |
| `N > M`，暂无合格空闲实例 | 暂时超出保活数，等待实例空闲超时；不会停止在用实例 |
| `N > M`，有合格候选 | 正按空闲时间回收超额实例；销毁中实例仍计入总数 |

全局总数来自服务端权威实例目录，不从会话历史页、当前工作空间、搜索结果、可见分页或在线客户端数计算。建议配置按宿主代理池统一，工作空间筛选仅改变列表；后台记忆/摘要等实例是否纳入此管理面需按统一方案明确列示，不能混入一个不完整的“全部”数。

### 3.2 实例行的状态互斥

| 实例状态 | 关联会话 | 行内动作与解释 |
| --- | --- | --- |
| 预热中 | 无 | 展示进度/原因；不能称已就绪或已连 MCP |
| 池中空闲 | 无 | 已可分配，显示池内连续空闲时间；无需再“归还” |
| 绑定准备中 | 目标会话 | 展示恢复/注入阶段；未完成不能执行 |
| 运行中 | 有 | “归还…”选择两种模式 |
| 会话空闲 | 有 | “归还池中”，无待执行任务不启动模型 |
| 等待安全点/归还中 | 旧绑定/操作归属 | 显示选定模式与进度，禁重复操作 |
| 刷新/清理隔离中 | 有或无 | 不可分配，显示脱敏原因，不能伪报空闲 |
| 销毁中 | 无 | 等待实际退出，不提供强杀按钮 |

总览分组与实例行使用同一状态模型，互斥计数合计等于全部数。运行中的工具/模型/权限等待不能被显示为会话空闲。客户端计时只作显示，到期资格由宿主判定，不靠 UI 时钟决定归还或销毁。

筛选行显示“匹配 X / 全部 N”；无匹配不等于池为空。搜索支持安全实例 ID、会话名称和工作空间，不搜索/暴露凭据、完整配置或系统提示词历史。

## 4. 实例详情与会话关联

展开详情建议显示：完整实例 ID、工作空间、当前绑定会话、绑定代次、创建时间、空闲起点、资源版本/实际加载时间、正在等待的阶段和脱敏错误。租约等诊断信息按权限折叠，不向模型或普通错误泄漏私密材料。

- 区分**工作空间当前资源版本**与**此实例实际已应用版本**；“准备刷新”不能显示为“已最新”。
- Skill 展示全集数量与本会话模型可见目录数量，不把目录条目数当正文已加载数。
- MCP 区分目录可用、未连接、连接中、已连接及关闭中；数量按当前绑定会话，不暗示池共享连接。此草案不做独立 MCP 管理台。
- 系统提示词仍可在原会话环境查看当前生效内容；池面板只需版本/时间/来源，不另建提示词历史档案。静态预览不能冒充某实例实际已应用。
- 归还后会话环境显示“未绑定实例／已归还”；旧环境若保留诊断标为“上次运行”，不得当成当前活绑定。

操作基于稳定实例 ID、业务会话 ID、绑定代次和请求 ID。旧行、换绑后的旧菜单不得作用到新绑定；这属于生命周期事务准入，不是每轮资源/profile 校验。

## 5. 安全归还交互

### 5.1 运行中：明确选择模式

点击“归还…”展开小菜单，不默认选中自动续跑：

- **归还并暂停**——安全点停止，将实例归还池中；之后可点“重试”继续。
- **归还并自动续跑**——安全点停止、归还，重新领取实例并注入最新资源，继续未完成任务。

菜单常驻说明：“不删除会话或历史；归还是回池保活，不是销毁。已完成工具操作不会因恢复而被整批重放。”动作使用归还/循环图标，不用垃圾桶，不混入清空历史或强制终止。

点击明确模式即提交一次意图，显示受理与阶段。除非以后引入破坏性动作，不叠加每次都要确认的通用删除对话框。未完成任务的判断以服务端恢复状态为准；会话已自然完成时解释“任务已完成，仅归还实例”，不为了兑现续跑按钮而发空模型请求。

### 5.2 阶段呈现

```text
等待安全点 → 正在结算与归还 → 已归还池中
                               ├─ 已暂停 [重试]
                               └─ 重新领取 → 加载最新资源 → 恢复中 → 继续运行
```

- 等待安全点时说明正在等待模型/整批工具/写入结算，不给未经测量的倒计时，不把长耗时当成功。
- 真正归还成功才能显示“实例已归还”；自动续跑尚未成功时不能合并显示“已恢复”。
- 旧实例归池后可以被别的会话领取，所以暂停/恢复状态按**业务会话和操作 ID**保留，不挂在原实例行上。
- 队列中待处理输入有明确数量和归属；归还中的新输入不进入旧绑定。暂停时保持待处理提示，恢复后交给新绑定；未知交付状态按下节处理。
- 关闭面板、切换会话不取消操作；用户显式停止/删除/撤权使旧自动恢复失效，UI 同步真实终态。

### 5.3 空闲绑定与池中空闲

会话空闲且没有未完成任务时，只提供“归还池中”。归还成功不生成模型请求；将来的普通消息仍按 ID 查绑定，无绑定再领取。

已经在空闲池的实例不再显示“归还”，也不把“刷新资源”误命名为“销毁”。普通实例销毁由总数与实例空闲 AND 策略负责，本轮不新增手动销毁、批量全池回收或强杀入口。

## 6. 暂停、重试、失败与断线

| 状态 | 展示与允许动作 |
| --- | --- |
| 安全暂停且已归还 | “已暂停 · 实例已归还”，提供“重试”和打开会话 |
| 自动恢复中 | 标明领取/资源刷新/业务恢复阶段；禁重复重试 |
| 恢复明确失败且可安全继续 | 脱敏原因＋“重试”；保留任务与历史，无暗中无限重试 |
| 工具或输入交付结果不确定 | 明示可能已经执行，先核对记录；不提供会自动重放副作用的通用重试 |
| 请求提交回执未知 | “操作结果待确认”，查询原请求结果，不换请求 ID 自动重发 |
| 断线 | 显示最后同步时间、数据可能过期，禁提交归还/续跑/设置，不把总数归零 |
| 重连 | 取得权威快照和原操作回执后恢复按钮；不是直接重复提交旧操作 |
| 会话/实例已经变化 | 明确“绑定已变化”，刷新关联；绝不对相同行号的新实例执行旧动作 |

“重试”按钮执行未完成业务任务的程序化恢复，不需要用户重复写原要求，不额外伪造一条 user 消息。新提示词在绑定时注入，不恢复旧提示词版本；工具配对、有效摘要、用量和任务归属继续保留。

恢复记录建议只展示活跃/待处理/最近结果的脱敏摘要，可被已有业务状态重新构建；不由前端保存另一份聊天/提示词历史。若状态通道乱序，丢弃旧修订；断线后按全量权威快照纠正，不能将迟到成功覆盖新停止。

## 7. 三个配置项

| 字段标签 | 建议值 | 帮助文字 |
| --- | --- | --- |
| 最大保活个数 | 8 个 | 统计全部存活实例；不是最大并发数，允许暂时超出 |
| 会话空闲回收时间 | 10 分钟 | 会话无执行或待处理工作达到该时间后，实例解绑归还池中 |
| 实例空闲回收时间 | 15 分钟 | 实例在空闲池达到该时间，且全部数量超出保活数，才销毁 |

建议使用显式“保存”按钮同时提交三个值：正整数、单位清晰，非法/空值就地报错；`0`不隐式代表特殊开关。该交互比三字段依次自动保存更容易说明组合规则，是建议而非现有设置行为变更。

- 编辑草稿不被后台状态刷新覆盖；若另一客户端改变设置，提示冲突并显示已保存版本，用户选择重新编辑/加载，而非静默覆盖。
- 保存有版本化确认，失败保留输入；保存成功显示应用时间，不将已编辑但未保存的值用于顶部阈值。
- 降低阈值只触发正常候选评估；不强杀在用实例，也不清空整个池。修改时间阈值重新计算资格，不把全部空闲起点改为保存时间。
- 未连接或保存未确认时不能说“已生效”。重连先核实原设置操作结果。
- 文案固定说明：**会话回收是归还；实例销毁必须总数超限且池内空闲超时。**

## 8. 空态、窄屏与可访问性

- 真正无实例：“暂无存活实例。会话使用时按需求领取并补热。”只有建议的显式工作空间准备路径可另触发预热，打开面板本身不触发。
- 状态读取失败：“池状态暂不可用”，保留重试读取，不伪报零实例；工作空间无匹配另显示“当前筛选无结果”。
- 桌面抽屉建议宽约 760–960px，随窗口限制；窄屏全宽，列表改卡片，优先显示状态、绑定会话和操作，详情折叠，避免水平拖动才能归还。
- 非模态面板不拦住会话继续显示；窄屏遮罩若采用模态模式须正确管理焦点。`Esc`仅关闭面板/菜单，不取消后台操作，关闭后焦点回入口。
- 支持键盘打开模式菜单/选择/保存/重试；按钮和阶段有可读名称，状态不只靠颜色，错误在字段附近且可被辅助技术感知。
- 进度用礼貌播报，计时不每秒抢占读屏；列表实时变动不抢焦点或自动打开会话，按稳定 ID 保持行身份。
- 不增加永久高频轮询或大段渲染；复用应用订阅/快照同步机制，面板关闭可释放展示订阅，后台生命周期继续运行。

## 9. 接入边界与未来验收

上述状态/API 字段是拟议语义，不声称当前 HTTP/WebSocket 已提供。新增状态投影应只承载池状态与操作回执，不传 MCP 请求、连接句柄、执行闭包或秘密。既有会话消息、权限、队列和计费协议继续沿用；前端不再造调度器。

以下为**未来实现后**的 UI/宿主 fixture 验收，本轮未运行浏览器、产品测试或真实服务：

| ID | 场景 | 验收断言 |
| --- | --- | --- |
| U01 | 打开/关闭/切会话 | 不创建会话/模型/MCP连接；面板状态不随会话 key 丢失，关闭不取消操作 |
| U02 | 全部计数与筛选/分页 | 总数来自权威目录，分类互斥、覆盖全部状态；筛选不改总数，退出确认才减数 |
| U03 | 总数超阈值 | 不出现硬容量阻塞文案；无超时空闲实例不强杀，提示等待真实候选 |
| U04 | 忙/闲/预热/池空闲的动作 | 按状态展示正确菜单；池空闲无重复归还、无待执行任务不发起续跑 |
| U05 | 两模式安全归还 | 等待安全点→归还→暂停或恢复分阶段展示；未完成不报成功，无默认自动续跑 |
| U06 | 归还后原实例改绑别人 | 原会话仍能看暂停/重试记录；旧按钮不能操作新绑定；恢复不要求原实例 |
| U07 | 重试与自动恢复 | 同一操作的重复点击/重送不产生重复领取或并发恢复；无假user消息/整批工具重放/重复用量；明确失败后的合法重试不被禁止 |
| U08 | 输入等待和未知结果 | 队列归属可见，无双交付；不确定副作用不开放盲目重放按钮 |
| U09 | 断线/回执丢失/重连/乱序 | 最后快照有过期提示，不归零/自动重发；按请求回执和新修订恢复真实状态 |
| U10 | 设置校验/冲突/保存失败 | 三项原子提交，单位及AND说明明确；冲突/回执丢失保留草稿，重连查询原操作而非重复保存；无未确认生效或保存即重置计时 |
| U11 | 当前资源与实例资源/旧环境 | 预览/上次环境/实际应用区分，旧准备不标最新，无提示词历史副本 |
| U12 | 只读错误和空态 | 真空池/无匹配/读取失败区分；重试读取不创建实例或激活MCP |
| U13 | 窄屏/键盘/读屏 | 操作可达、焦点正确、Esc不取消后台操作、状态不只颜色，无计时播报轰炸 |
| U14 | 状态与动作秘密保护 | 不泄漏凭据/env/URL秘密/完整服务配置；名称和不可信错误按普通文本渲染 |
| U15 | 并发客户端与用户停止 | 操作幂等、版本冲突可见；旧续跑不覆盖停止/撤权/删除，原会话关联不串用 |
