# 客户端独立发布

客户端版本为 `0.4.8`，桌面端采用深色连接页：保留“就绪之后，专注创造。”、设备菜单、实际环境检测标签和常驻本地服务检查／启停。竖屏端口与连接按钮左对齐相邻，间距12px；按钮44px，插头图标21px。浅色主题暂不提供。状态读取失败显示待核实，避免依据旧状态停止服务。

发布范围为 Windows x64 EXE／MSI、macOS 通用 DMG（arm64／x86_64）、Android APK 及同源 AAR。Linux 使用浏览器，没有原生安装包。Android 使用原生地址输入及成功连接历史；深色桌面控制页不替代 Android 原生入口。

该版本只分发客户端，不构建或上传后台包，不推送 master，也不触发后台自动发布。客户端独立 Release 不设置为 Latest，后台的一行安装与更新继续使用现有正式后台版本。客户端从固定版本 Release 手动下载；旧客户端的自动更新入口不保证发现该独立版本。工作台内容由所连接的后台提供。

版本以发布 tag 的根 package.json 为准，五个分发版本文件保持一致。Android 复用原签名，以允许覆盖升级；Windows 未代码签名，Mac 使用 ad-hoc 签名且未经 Apple 公证。发布附件附 SHA-256，公开后核对下载字节。

客户端构建和验收使用隔离目录、独立测试应用标识、数据及端口。正式包不得包含调试／自检入口。Windows 与 Mac 分别验证原生启动、控制页／工作台切换、连接与服务生命周期；Android 分别记录编译、签名、安装及可用设备上的连接检查。不能将浏览器夹具或APK静态校验描述为实体设备验收。
