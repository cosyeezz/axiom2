# 层级唯一目录、文档引用与记忆查询

本文说明当前实现：**持久化唯一目录节点 → 全树一次匹配完整标题路径 → 节点直属文档直读 → 原文归纳**。替代此前逐层导航、详情二次选择及短编号投影。历史目的流程见[目的流程实施记录](memory-refactor/purpose-implementation.md)；其中旧查询协议及旧验收数字不代表本轮结果。

## 原记忆与目的身份

`MEMORY.md` 是只含状态标题的执行树：一级标题是目的，后代标题是执行步骤，支持六态及英文状态。正文按完整标题祖先链放在 `details/<祖先标题>/<当前标题>.md`；一级自身详情是 `details/<一级标题>.md`，按需创建，主记忆不写链接或编号。混入正文、非法状态或层级的源文件跳过，不调用模型修复。只有一级已完成且没有未完成活动后代的目的入队。

目的 ID 持久绑定来源会话、`MEMORY.md` 和不可变一级标题。同父标题须唯一（含大小写和 Unicode 等价），不以行号或子树相似度猜身份。根重排、新增详情不换目的 ID；取消保留分支及原详情，标记 Abandoned。存量不兼容文件不自动改写。

分类语境入队时冻结：同一文件相邻最多四个其他一级目的的标题、状态及原顺序，仅作语境，不读取其正文，不将其算入本批条目。

## 持久队列与分类发布

- `memory_purposes` 保存目的身份、首次入队、处理状态、退避及冻结语境；`memory_purpose_indexes` 保留组织器使用的无损目的树及版本。
- 达到 **50 个目的**或最早等待 **30 分钟**时触发分类，共用全局互斥槽；每批最多 50 个，等待时钟重启后保留。
- 模型只收到已有分类树、目的 ID、目的文本及冻结语境，无读取工具，不收到来源会话、文件路径和正文。
- 输出多叉树：目录 `{name, children}`，目的叶 `{purposeId}`。每个已发布及本批目的恰好出现一次，不遗漏、合并或伪造目的身份。
- 新生成目录名称仅接受中文或英文字母。现存目的标题不因此被改写；含数字、空格或其他历史字符的标题保留原样，进入迁移预检报告。是否放宽新目录的数字、空格规则及后续语义重整仍另行确认。
- 一级目录名称连同换行不超过 **1000 Unicode 字符**；完整分类输入按 `readChars` 校验，超限拒绝整次结果，不截断旧目的、本批条目或标题。目前仍是全树重分类，预算外会进入可重试失败状态，不宣称无限规模。
- 分类前后核对来源、授权、目的身份、队列与索引版本。成功后在同一事务内发布旧目的树、新目录节点及引用；失败回滚，保留旧树与队列并退避重试。撤销中的目的不能被迟到结果复活。

## 唯一目录节点与文档直连

`memory_directory_nodes` 是查询与全局记忆界面的目录数据源：

| 字段 | 约定 |
| --- | --- |
| `id` | SQLite 数字 ID，从 0 起，由持久计数器分配；不随排序变化，不把旧 ID 分配给别的路径。接口转字符串，因此 `"0"` 是有效身份。 |
| `workspace_id` | 工作空间隔离。 |
| `title`, `parent_id` | 原标题及父节点；一级父为 `-1` 虚拟根，不新增实体根。 |
| `depth`, `ancestor_ids` | 一级深度为 1，保存完整祖先 ID。 |
| `title_path` | 从一级到当前节点的标题，以 ` / ` 连接，例如 `工程实践 / 记忆查询 / 冻结目录`。程序统一生成。 |
| `purpose_ids` | 与当前路径对应的全部来源目的 ID。 |
| `document_refs` | 当前节点直属文档集合，包含来源会话、相对路径、标题、状态、所属目的及祖先状态语境。 |
| `position`, `active` | 稳定排序位置和活动标记；不再出现的路径保留墓碑记录。 |

数据库约束为 `UNIQUE(workspace_id, title_path)`。相同完整路径合并为一个节点，所有来源目的与文档均保留。不同父节点下的同名标题仍是不同节点。同路径的“目录”和“目的叶”也合并，**节点可以同时有直属文档和子节点**，不使用 `is_leaf` 限制。

路径不能含 `/`、反斜杠、控制字符或首尾空格，避免分隔歧义；遇到不安全存量路径拒绝该次迁移/发布，不静默清洗。预检报告保存同路径合并项与历史标题项。

文档以 **`(sessionId, path)`** 去重，并合并关联目的。扫描依据原记忆标题范围、完整祖先链和实际文件元数据建立引用，不由模型选择或生成路径。保留放弃状态及祖先语境，避免历史失败被当成成功结果。

`memory_purpose_documents` 保存按目的追加的引用；普通扫描发现新增详情时去重追加，不删除历史引用、不重新分类已处理目的。被撤销来源不进入活动节点视图。源文件缺失时不会因缺失而改写或清空历史引用，读取时逐份处理。

### 旧数据回填

1. 建表后，从已发布 `memory_purpose_indexes` 的数据库元数据幂等回填节点、路径和来源目的，不重整语义，不读取原文正文。
2. 正常成功扫描各会话时，按实际存在的详情文件补充文档引用；此步骤放在“源内容未变化”的提前返回之前，已分类旧目的仍能获得新详情。
3. 引用有变化才更新索引版本并事务发布节点；重扫不重复添加、不重复增加版本。
4. 查询及快照读取不扫描源文件；构造器也不做全库文件扫描。因此旧库仅完成元数据迁移、尚未完成正常来源扫描时，节点可能暂时没有直属文档，不能据标题凭空作答。

`memory_node_sequence` 保存下一个数字 ID，`memory_node_indexes` 保存每个工作空间节点版本、发布时间及迁移预检报告。迁移和发布失败时节点、计数器、报告与原索引一起回滚。

## 主会话目录与压缩

主会话仅注入一级分类纯关键词和查询提示，不注入 ID、位置、来源、文件路径或 JSON。目录用于提示何时查询，不是查询范围，也不是答案依据。

主会话目录快照沿用 payload `version: 2`。旧 `version: 1` Topic-ID 快照不转换、不删除。新会话首条输入前记录目录；普通消息、重载、首条输入重写和选定分支恢复沿用该分支快照，不每条消息刷新。缺少有效新版快照时，在安全点写入最新目录。

压缩排除新关键词目录和旧 Topic 目录，保留原生完整摘要与安全应用链路。仅成功应用后注入最新目录；取消、失败、修订冲突不推进快照，不从废弃分支取快照。

## `memory_query({ question })`

工具只接受简短、自足的问题，不接受 Topic、目的 ID 或文件路径参数。不依赖委派或通知；整理与查询继续复用统一执行池、模型配置、取消/供应商停止及用量统计。

### 查询步骤

1. **冻结完整目录快照**：首次取得当前已发布节点树时冻结，包括标题路径及文档引用绑定。查询中不扫描、不整理，不因并发发布或新增引用而换版本。
2. **全树一次匹配**：发送 `catalog` 字符串，格式为 `目录：` 加两空格逐层缩进的完整纯文本树；无短编号、ID、文档路径、来源元数据，无关键词预筛、前 N 项或截断。
3. **精确路径定位**：模型只返回 JSON 字符串数组，例如 `["工程实践 / 记忆查询"]`，可多选；`[]` 才是正常无匹配。程序严格校验快照内精确路径，伪造路径、重复路径、错误类型、非法 JSON 或歧义绑定均为执行错误，不当成空匹配。
4. **批量读取直属文档**：将所选节点的直属引用按会话及路径去重，完整分页读取。无需为定位而读取 `MEMORY.md`，也没有第二轮详情选择。只选父节点不隐式读取后代文档，模型可一次选择多个层级节点。
5. **读取直接显式引用**：详情中的直接 Markdown/文本链接仍经原有路径与权限检查；相对路径以该详情为基准，不递归展开，不读取原始对话 JSONL、脚本或任意数据目录。匹配前同时冻结已有文档来源绑定；链接若指向另一目的的详情，保留目标本身的目的、状态及祖先语境，并核验目标目的未撤销，不冒充链接所在目的。无目的绑定的参考材料不被赋予虚构任务状态，并记录链接来源。
6. **归纳原文**：只用成功读取的原文归纳做法、方案、路径、成功/失败经验，保留条件、版本、分歧和未确认项。正常有证据时查询共两次模型调用：全树匹配、原文归纳。无匹配或无可读正文时不调用归纳，不凭标题作答。
7. **发布前核验**：复查来源/读取权限（包括当前文件系统可读权限）、目的仍有效及纠错信息；撤销、撤权或命中纠错会屏蔽输出。每次实际读取将同一次路径解析所得的规范实际路径与内外部属性，以私有弱映射绑定到该页正文，不用读取前后另一次路径解析猜测，不向模型或客户端发布。外部资料先独立核验当前声明仍授权已捕获路径，再检查目标；仅目标自身消失可保留已读字节，不能以 `ENOENT` 忽略声明撤销。已消失的符号链接不猜测其旧身份。已经完整读取的文档随后修订，不单凭后续字节变化撤销此次已冻结证据；分页读取期间版本或规范实际路径变化均视为冲突，即便两份文件正文完全相同。

### 空返回与真实失败

- `[]`：正常 `no_match`。
- 节点没有直属文档，或关联文件全部不可用：正常 `no_evidence`。
- 单份文件缺失、无读取权限的文件系统错误或不支持的二进制文件（含 NUL 或无效 UTF-8）：跳过该文件，不拖累其他可读文件。外部链接声明的枚举、哈希及解析同样逐份隔离这些错误；被跳过或消失的声明不保留旧授权，其他有效声明仍可使用。此容错只用于声明收集，不放宽正常索引扫描及路径安全检查。
- 路径/来源越权、无效协议、真实模型/执行错误、超时、取消、关闭或读取中的修订冲突：不伪装成成功空匹配，按现有错误/不完整结果契约返回并记录。

默认答案直接给结果，不附来源会话、目的 ID、哈希或检索流水；用户实际需要的项目路径必须保留。内部处理记录保留冻结版本、路径与节点身份绑定、实际模型调用、所读文档及修订。阶段包括“读取完整目录快照”“全树一次匹配”“批量读取关联文档”“归纳原文答案”“查询结果已核验”，不再记录虚构的逐层导航或详情选择。

## 纠错与全局记忆界面

原文纠正保留 CAS/字节身份与私有纠正记录；先事务撤销受影响派生目的再写原文，避免崩溃窗口或迟到分类复活旧内容。独立详情按完整标题路径反查目的，其他直接资料保守撤销来源。合法重扫复用原目的身份。

界面保留脑图、搜索、拖动缩放、适合画布、全屏、触控及键盘导航：

- 任意节点可选中；选择查看与展开/折叠是不同按钮，不会互相触发。
- 节点徽标显示**直属文档数**，不累计后代；数字 ID `0` 正常显示及连线。
- 右侧展示完整标题路径、直属文档列表，含标题、来源会话名和相对路径；多于八份时提供本地筛选。
- 文件按会话及路径去重。打开复用已有带权限校验的原文预览，不通过模型浏览或生成摘要。
- 原始目的与来源放在可展开的“来源信息”中，不再冒充节点正文。
- 无文档显示空态并提示查看子节点；单文件预览失败仍可返回节点列表打开其他文件。

查询/整理模型、执行时限、分类输入上限及处理记录入口保留。每次模型调用只计费一次，父工具结果不重复计费。

## 验证边界

本轮验收只使用临时 SQLite、临时记忆文件、假模型及本地 HTTP 假供应商；浏览器验收使用隔离服务与临时构建目录，**不覆盖 `dist`**。相关测试包含 `memory-nodes`、`memory-tree`、`memory-query`、`memory-query-projection`、`memory-io.integration`、`memory-summary`、`session-memory`、`processing-records`、`memory-map-layout` 及脑图/全局记忆浏览器检查。

重点覆盖 ID 从零开始及稳定性、不复用、同路径多来源与目录叶合并、迁移幂等、正常扫描回填及追加、事务回滚、祖先放弃状态、冻结引用、精确路径协议、单文档不可用、权限/撤销/纠错、真实错误、分页冲突、取消/超时/关闭及两次模型调用。

目前来源引用有变化时仍在同步事务中重建工作空间节点视图；存量逐来源回填和大量墓碑可能放大写入成本，尚未做规模化性能压测。该风险不应被两次模型调用的查询优化掩盖；后续可按来源读取队列并批量刷新受影响节点。

没有触碰正式数据库、调用真实模型、清理历史数据、部署或重启后台。真实模型语义质量、正式库迁移效果、长期负载及后续语义重整仍未验证；实际启用需要另行授权。
