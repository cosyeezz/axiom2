# 卡片图标候选来源与许可

这是选型材料，不表示已将这些图标接入产品。图标由原作者创作，经 [Iconify](https://icon-sets.iconify.design/) 目录及公共 SVG API 获取；保留原始造型和线宽，没有手绘或旋转凑数。

每类50个，共350个候选项，跨分类可能复用符合不同语义的图标。每个图标的来源、作者、许可名称/链接和内嵌SVG素材哈希见 [完整清单](component-icon-options.json)。选图页内嵌SVG，打开后不依赖网络加载图标。
