# 组件能力图标选图器

[打开统一多选选图页](component-action-icon-picker.html) · [候选清单与来源 JSON](component-action-icon-picker.json) · [已确认的能力与状态逻辑](component-capability-state-logic.md)

## 使用

1. 点击卡片或右上角复选框勾选，支持同类多选；用顶部按钮切换类别，已有选择不会消失。
2. 六类可一起选完，点击 **复制全部选择**，把结果一次粘贴回会话。默认反馈包含 **类别、编号、Iconify ID**；也可切换为 JSON。
3. 若自动复制被预览限制，点击 **全选反馈文本** 后按 **⌘C / Ctrl+C**；触屏可长按文本复制。页面只在复制方式明确返回成功后提示“已复制”，失败会保留可选择文本并说明限制。
4. 可搜索编号、ID 或语义，打开“只看已选”核对。清空后可撤销；误关预览前可先复制一份，重开后在“从已复制的反馈恢复勾选”中粘贴恢复。
5. 短高度内嵌预览会取消顶部吸附，避免工具栏遮住候选或反馈框；可随时点右下角 **↑ 选择与复制** 返回操作区，不会清空勾选。

隔离预览可能禁止本地存储，因此不会承诺关闭后自动保留；同一次打开期间切换类别、搜索或筛选不会清空选择。普通浏览器若允许本地存储，会尽力保留勾选。

## 范围

| 类别 | 编号 | 数量 | 语义边界 |
|---|---|---:|---|
| 清理安装包 | P-01～P-50 | 50 | 只清理登记缓存，不卸载程序 |
| 下载安装包 | D-01～D-50 | 50 | 仅下载，不执行安装 |
| 使用缓存安装 | K-01～K-50 | 50 | 复用本地缓存，不代表已经安装成功 |
| 打开系统安装器 | O-01～O-50 | 50 | 打开系统流程，仍需用户完成 |
| 切换版本 | V-01～V-50 | 50 | 可能升也可能降，不一概表示更新 |
| 修复组件 | F-01～F-50 | 50 | 区别于重装，已有通用扳手仅作候选参照 |

共 300 个分类候选项；同一图形可能适合不同类别，类内 ID 唯一。清理包沿用之前的 P 编号与 SVG，K 避免与已选组件 C-25 混淆。没有默认选中项，最终选择由用户决定。

“缺失”指缺少独立已选组件动作图标，不代表仓库完全没有对应图形。既有检查、安装、更新、重装、卸载等已选图标不变；说明、外链、查看包继续复用现有符号，不为每个状态另造图标。

## 预览与安全

- 图形、样式、脚本与使用到的完整库级许可正文均内嵌，页面自身不需要联网。
- Axiom HTML 预览须开启 **脚本** 才能汇总与复制；无需开启联网。关闭脚本时仍可原生勾选，但不能汇总。
- 兼容现有双层 `sandbox="allow-scripts"`，不要求放宽 `allow-same-origin` 或剪贴板策略，不访问父页面，不发送应用命令，不执行维护。
- 可在外部浏览器直接打开同一个 HTML 文件作为另一条可用路径。
- 原预览不能选中的瞬时原因尚未复现，不能把仅 `file://` 测试通过当作 Axiom 内嵌预览也必然可用的证据。新版验证覆盖真实 `HtmlFile` 双层隔离预览，并以隔离工作台验收实际助手文件链接、`files.document` 读取及文件面板交互；不等于已安装桌面 App 或真机长按菜单验收。

## 来源与许可

候选使用 Iconify 网站/API 或其上游图标集的实际 curl 响应；页面提供每项来源，以及各库作者、上游许可、本地快照和全文。库级许可沿用 [52 库已收集索引](component-icon-options-licenses/index.json)，生成时校验 SHA-256；不等于不可变图标版本或逐图法律放行。CC-BY 图标仍需署名，MDI 存在第三方例外，最终采用前仍须履行实际来源的许可。

生成器与可复用证据位于 [artifacts/component-icon-picker](../artifacts/component-icon-picker/)；构建仅使用保存的资产，不重新拉取已验证候选，也不修改应用图标或业务逻辑。本轮只交付选图材料。
