## 2. 直接 import 统计看不到的具体边界

1. **枚举和字符串协议。** shared 的 Thinking/off→model reasoning/none、followUp、toolResult、commentary/final_answer、functions.、native compaction marker 都没有 Pi import。适配时必须显式映射，不应把这些现有 UI DTO 当成底层 runtime 公共协议。
2. **原生存档中的 Axiom metadata。** [memory-tree.ts:39-41](/Volumes/D_Work/axiom2/app/src/server/memory-tree.ts#L39) 保留 Pi custom-entry identity；[canonical-projection-native.test.ts:19-37](/Volumes/D_Work/axiom2/app/tests/canonical-projection-native.test.ts#L19) fixture 使用 `axiomId/axiomRunId/axiomInputIds/axiomSelectionChange`、Pi session version 3、parentId/compaction/context_edit。替换 import 不会迁移这些持久语义。
3. **显示投影不是上下文。** [canonical-source-capture.ts:33-47](/Volumes/D_Work/axiom2/app/src/shared/canonical-source-capture.ts#L33) 要求完整、可信、同 capture 数据，但明确不建立 native branch/file/cache generation；[canonical-occurrences.ts:100-107](/Volumes/D_Work/axiom2/app/src/shared/canonical-occurrences.ts#L100) 不证明 wire/RSS bound；[canonical-overlay-holder.ts:18-23](/Volumes/D_Work/axiom2/app/src/shared/canonical-overlay-holder.ts#L18) 只做本地 writer/receipt 生命周期，不是 lineage/persistence/授权。这些纯模块测试不能证明跨进程一致性。
4. **传输权威不是命令成功/持久性。** `scopeAuthority` 排除 synthetic/旧 generation/断订阅事实；实际 null 才能证明不存在；`renderedContextReady` 同时要当代 messages/thread/agent。统一 adapter 后不能简化成“最后 seq 最大就是权威”。

## 4. 对现有适配器提案的对照建议

提案方向与上述事实一致：宿主持有任务/费用/授权/池，adapter持有native loop/历史/安全点；ModelGateway独立；input-queue/configuration/history/branch/context/recovery扩展，不强制通用原生上下文。

需补充到落地清单（不必扩张最小核心）：
1. **T层契约必须保留**：streamId/wire seq/connection generation/订阅lease、read.cancel、1013 overflow与权威快照补偿，不要与RuntimeEvent.seq混用。
2. **既有UI DTO兼容映射表**：Thinking枚举、followUp、final_answer、toolResult、taskNotice、selectionChange、inputIds、未知context/费用及legacy字段。输入枚举拼写和native模型reasoning不直接透传。
3. **离线归档端口输出可验证 projection revision**，涵盖context edit、archive/live物理桶、正文details revision与images只读定位，不是只返回messages数组。
4. **产品场景门禁**：skills/MCP CapabilityCatalog与RuntimeCapabilities拆名；无native-history/phase/usage等能力时UI真实降级。新/旧会话持久runtime归属以及adapter缺失须显式unavailable。
5. **保持旁路能力不依附完整agent会话**：Model/auth/usage、file/preview/OS、memory/title jobs、资源安装维护与backend update仍是宿主服务，不宜一概移到adapter。
6. 第一轮验收同时跑（未来安排，不是本轮执行）：Pi现有纵向回归、FakeAdapter中性契约、真实wire/transport权限与背压、独立browser能力门禁；报告fixture/remote/platform分级与实际exit code。
