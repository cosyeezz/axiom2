## 建议的最小抽象边界

1. `ArchiveReader/ArchiveWriter/NativeArchiveCodec`：只在Pi adapter中认识 `SessionManager/SessionEntry/CompactionEntry/AgentMessage`；公开 opaque session/entry/message refs、活动分支投影、原文投影、只读打开、snapshot、context edits、fork/rewrite和可核验持久化receipt。不能只暴露 messages[]+save/load。
2. `RuntimeArchiveControl/RuntimeResume/RuntimeCompactor`：在线边界排队、串行安全点、请求permit、无工具摘要、native continuation/reload lifecycle。恢复模型是运行时能力，不能假装离线storage操作；本审计未运行这些路径。
3. `Host SessionCatalog/ForkCoordinator/RecoveryCoordinator/CompressionCoordinator`：保留SQLite权限、幂等、UI分组、memory policy、队列和写者租约，不下沉到Pi通用接口。
4. `CanonicalCaptureAuthority`：当前缺失端到端scope+file/cache generation+原生正文版本+pending overlay admission证明；metadata link/本地owned copy各自不足。先补契约与集成设计，不把helper名义当已完成能力。

## 新增易遗漏项（相对“只有存取/分支/压缩”清单，非声称仓库新增）

- **只读打开与可写恢复严格分离**：Pi open会修尾换行；inMemory+parser才保证浏览不写盘。
- **原文仍遵守context_edit和活动分支**：不是把整个JSONL全树dump给UI。
- **来源双版本**：源文件身份/时间戳/contextRevision 与 overlay值版本/receipt不可合并为一个“loaded”布尔。
- **message_end早于落盘**、draft早于commit；观察returned/metadata link不拥有正文，也不是disk receipt。
- **空fork header强制持久化**；commit后publish失败不可删已被DB引用的native file。
- **中断tool副作用未知配对**：不能“重试”原tool，也不能造success；旧失败/缺result历史不应整体阻止摘要。
- **重写marker全树扫描**仅用于抑制废弃结果/continuation归属，不能借此恢复废弃正文。
- **双压缩系统并存**：Axiom后台压缩与Pi70%安全网独立；后者提交后旧后台结果必须作废。
- **retain-none自引用、零keep仍保留cut点、nested fileOps**：均是原生压缩协议adapter义务。
- **cache优化允许降级，但摘要安全不许降级**：缓存损坏回native，不是失败；原生格式不匹配不能强行套前缀。
- **cancelled / applied / uncertain三态**：取消收费summary不等于已取消live queued apply。
- **分段UI物理边界不等于模型keep边界**；跨桶分组需先完整轮次后裁剪。
- **费用逐physical attempt定价，usage provenance和unknown必须保留**；不能声称涵盖SDK transport重试或crash atomic。
- **业务restore≠runtime resume≠resource reload continue**；三者权限、系统prompt和副作用语义不同。
- **canonical helpers尚无生产接线**：在app/src静态检索仅见定义/内部helper调用；现用AgentViews仍旧transient。不能报告已解决native authority或获得增量性能收益。

## 已知风险、未验证与范围限制

- `transcriptHeader/openTranscript`读后比对dev/ino/birthtime检测替换，但不声称防止同inode并发内容变化；缓存source虽含size/mtime/ctime，也不构成原生body版本authority。拟议接口应明确writer exclusivity及generation验证。
- `compressionPersisted`的disk行匹配比manager内存更强，但不是fsync/断电durability保证；对于`isPersisted()===false`直接true分支需保留in-memory模式语义，不应泛称磁盘确认。
- fork/rewrite和compaction对JSONL及SQLite存在跨介质窗口；回执、native marker和启动reconcile是现有协调机制，而非完整两阶段事务。
- canonical occurrence/capture全量扫描复制、history全量原生解析、SQL分页的扫描排序成本都保留；不得把输出有界等同内存/CPU/IO有界。
- 本次深入读取指定文件及关联views/safe-point/context/recovery/SDK声明。provider专门Kiro计费guard、附件读取实现、task delivery全部流程未穷尽；其调用依赖已记录，未将未读实现当已证明保证。
- 未运行任何测试/模型；不能据本报告宣称运行时行为已测试通过。该文档是只读证据与接口需求清单，不是实现变更。
