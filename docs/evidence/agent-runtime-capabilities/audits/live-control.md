## 不应遗漏的实际抽象缺口（按优先级）

1. **结构化原生队列与原子撤回是硬缺口**：当前唯一直接读取私有布局的 native-queue.ts 不是可有可无shim。公开文本队列/peek不能保留全部custom metadata、图片及未消费身份。需要adapter的同步队列事务/按ID撤回/保留证据三值结果；不支持时必须显式禁用撤回而非返回空成功。
2. **生命周期钩子不是普通事件流**：safe-point安装覆写四个Agent执行入口，reload-resume又临时覆写prompt且有输入形态断言。backend能力须分别表达“可观测事件”与“可阻塞、可返回draft/decision、提交后的原生序列化边界”，否则模型切换、重载、压缩均有竞态。不能以idle polling降级冒充。
3. **持久化并非只要export/import messages**：现有实现读取/修改树投影、branch、context_edit、compaction draft、entry ID、native JSONL完整行及自定义metadata；还在持久化前改事件对象。需明示保存身份扩展点、持久record确认、有效context/原始/history三投影、修补未知工具结果等独立能力；不可把SessionManager暴露为通用接口。
4. **模型切换不是SDK setModel语义**：宿主明确跳过auth探测与thinking clamp，允许无效逻辑选择，真实request才失败，并对抗扩展覆盖。adapter必须报告是否能忠实实现；禁止静默fallback、联网catalog验证或沿用旧端点。
5. **会话/实例/租约/请求/UI身份需分层**：run与instance/generation/lease围栏、输入ID、toolCallId、消息ID、reloadId/压缩ID、外部幂等回执是不同作用域，不能统一为sessionId。协议当前广泛any，缺少可穷尽的事件联合与受理/入队/消费/持久/不确定状态定义。
6. **交互UI当前没有实现**：bindExtensions只设rpc mode和错误回调。已安装SDK的[绑定实现:2598-2620](/Volumes/D_Work/axiom2/app/node_modules/@earendil-works/pi-coding-agent/dist/core/agent-session.js#L2598)与[hasUI:404-406](/Volumes/D_Work/axiom2/app/node_modules/@earendil-works/pi-coding-agent/dist/core/extensions/runner.js#L404)证明缺uiContext时无交互。应分出运行展示（已有）、人类问答（未接）、终端自定义组件（不可移植）三层；不得称“RPC模式已支持扩展UI”。
7. **安全边界须保留在宿主**：DB事务、授权、epoch、provider撤销、预算、任务调度、幂等/recovery witness、进程树退出、唯一JSONL writer由宿主拥有；adapter仅提供不泄漏Pi类型的执行/存储原语。当前进程cwd/env/network隔离不是任意共享进程可等价替换；子代理命令allowlist不等于OS文件系统沙箱。
8. **热复用能力须可降级而非强制**：资源散列不证明任意JS import graph。外部资源、symlink、扫描超限应退为single-use并禁预热；snapshot/lease/config drift校验、实际close与清理ack仍不可省。worker源码hash不是传递依赖全量build hash。

## 推荐能力边界（由实际语义反推，不是旧接口重命名）

- 核心adapter：bind persistent conversation；submit（with identity/metadata/images/visibility/trigger policy）；typed event projection；settle/abort/dispose；atomic queue read/recall + retained tri-state；durable evidence + multi-view history；serialized lifecycle mutation hooks；logical model selection + request routing evidence。
- 协商扩展：reload（skills-only/full、pause/resume/no-user）、compaction（snapshot/propose/commit/cancel）、task phase/budget、host tools/context injectors、branch rewrite、usage/latency、human UI。任一扩展缺少必要原语，应不开放对应产品入口。
- 宿主port：lease/process supervisor、admission/DB transaction/receipt/recovery、permissions and tool policy、task/memory coordination、UI transport。backend adapter返回能力与故障证据，不能决定授权、自动重发或业务重试。
