- `thinking.type` → `reasoning.type` (off is **"disabled"**, on **"adaptive"**, not boolean/off literal).

- If all absent, omit reasoning; otherwise retain only present string fields. No budget_tokens mapping in this converter.
[thinking-effort.txt](thinking-effort.txt), byte **3655250**, L2242: model-directory schema supplies effort enum/default/path; toggle exposed only when enum includes disabled and adaptive. SEt constructs fields. When disabled and requested effort is xhigh/max, select last advertised effort not xhigh/max, or omit if none. Example conversion (static inference, not executed): `{thinking:{type:"disabled"},output_config:{effort:"high"}}` → `{reasoning:{type:"disabled",effort:"high"}}`. Dropping additionalModelRequestFields during Responses conversion loses intentional off/effort; preserve this mapping and independently test offline before considering any route change.
