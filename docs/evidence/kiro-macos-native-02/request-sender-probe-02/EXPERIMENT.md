# Instrumented V3 command selection, no model traffic

## Single hypothesis

With the confirmed command interface from help01, explicit V3 can reach the KAS Command factory and pass the static candidate auth/transport arguments plus an inherited, controlled NODE_OPTIONS marker. This is an instrumented selection test, **not** a natural default engine, actual sender/API, authenticated request or parity baseline.

## Inputs and intervention

One official `chat --v3 --no-interactive --trust-workspace --model deepseek-3.2 AXIOM_OFFLINE_SENDER_SELECTION_ONLY`, stdin EOF, own HOME/CWD/minimal environment. The sentinel supplies the parser's INPUT but cannot reach a model: sandbox denies all network and the real KAS executable/server are replaced *only in this process* by own collector/empty marker via KIRO_KAS_NODE_PATH and KIRO_KAS_SERVER_PATH. No extracted official JS, Node dependency or fake authstore is executed/created; real config and stored engine unchanged.

The C collector records only argument roles for controlled paths and allowlisted constant flags, lengths for all unknown argv, and boolean/enumerated projections of NODE_OPTIONS/NODE_USE_SYSTEM_CA/UA/port presence. It never writes unknown argument/environment values. A hardcoded own CreateNew trace path avoids depending on env inheritance to report. Max64 args, each4096B; own output <16KiB.

Sandbox denies real HOME reads, mach-lookup, global writes and network; only official launcher/chat/own collector may execute. Lack of login or a different execution path may stop before the collector; preserve that result without faking real credentials or loosening policy in place.

## Execution and budgets

Fresh binding of the two installed public binary bytes/SHA for this new execution, matching help01/frozen2.35.2. No signature/extraction/old-suite repeat. Direct installed CLT clang builds only own C helper; no shim installer or developer-directory change. Parent CPU10/wall30, compiler CPU5/wall10, official child CPU2/wall5, NOFILE64,64KiB per stdout/stderr stream, combined128KiB, all saved results <=2MiB. One unique namespace/results directory, CreateNew artifacts, one official launch, no retries.

Before the official call, independently test only frozen collector C privacy/roles/bounds in another own TEMP/minimal env; no official CLI/network/auth reads or repository modifications. Main does not change tested files while that runs. Tests cannot be relabeled as real sender evidence.

## Acceptance and evidence

Save preflight before official execution, exact controlled argv/env, source/collector hashes, sandbox, actual compile/official exits/times, raw fake-only streams and collector projection when present. A positive selection result requires valid complete collector JSON and projected server/wasm/transport/auth roles; CLI may fail because fake collector deliberately implements no ACP handshake. Missing trace is a negative selection observation, not proof all V3 paths are unreachable. Model availability and actual sender/API remain unproven in either outcome. No full-tree ownership/containment claim; M3 is not a prerequisite and its abandoned branch stays stopped.
