# Public SDK-only native containment research
Scope: user-reported UID501/macOS26.6.2 build25G83 ARM64; NOT independently queried. No runtime API test, process scan/control, network, HOME, credentials, target inspection, repository edits or installs. Only public SDK/man read; isolated /tmp artifacts. SDK directory listing shows 12.x/13.x only, MacOSX.sdk symlink ->13.3; SDKSettings.json confirms 13.3. No inference about absence of newer macOS26 interfaces.

## Method and collected evidence
Commands: find on MacOSX13.3.sdk for coalition/responsibility/spawn/audit headers and man; rg -n -i on usr/include, usr/lib/system/*.tbd, usr/share/man and Kernel.framework Headers for coalition, responsibility getters/setters, responsible audit token, spawn coalition; focused read of listed source files; find /usr/share/man for coalition/responsibility/audit/launch/endpoint names; rg for ES root/entitlement/TCC errors, deadlines and dropped sequence numbers; rg for audit session API and setaudit privilege; Python standard-library copy into numbered-evidence and SHA256 manifest. All executed shell collection commands returned 0; optional absent paths were suppressed, not treated as evidence of universal absence. No tests/builds run. No API invoked.

## Findings
1. Coalition symbols DO EXIST: libsystem_kernel.tbd 139-142 exports coalition_create/info/reap/terminate; 355 setcoalition spawn attribute; 371 proc_listcoalitions. These are linker export declarations, not public prototypes, permission contracts or semantic documentation. Kernel kern/coalition.h 32 says only kernel-private interfaces. Public spawn.h has no coalition attribute declaration (full file retained). No coalition/responsibility manual matched in searched local SDK/man roots. Cannot establish that coalition_terminate kills tasks, that membership is complete/inherited/non-escapable, that non-root can create/adopt/list/terminate/reap, or that completion notification is available to an ordinary caller. All UNKNOWN, not declared impossible or root-only.
2. Notification candidate: Kernel mach/coalition_notification_server.h 80-85 accepts port,id,flags. mach/host_special_ports.h 85-101 labels coalition port in not-provided-by-kernel group; 231-235 wraps host_get/set_special_port. This proves vocabulary, not caller ownership, entitlement, subscriptions, meaning of flags or terminal barrier. No API test.
3. Responsibility exports exist in libquarantine.tbd 31-44, no matching public contract located. ESMessage.h 83-86 explicitly permits responsible token to become self when responsible process exited; 64-70 distinguishes parent/original parent/group/session. libbsm audit_token_to_pid/version decode one identity, not tree membership. Therefore attribution is NOT an immutable full descendants set.
4. Additional non-PGID candidate: bsm/audit_session.h 147-152 documents AUE_SESSION_END = all session processes exited and CLOSE = record removed; 81-82 all-session monitoring requires privilege. This is a genuine public terminal signal candidate, but not proof of private descendant-only membership or bulk kill. audit.h 380-385 gates self/join/port under __APPLE_API_PRIVATE. setaudit_addr.2 125-149 requires appropriate privilege and explains unique session creation; 218-220 EPERM. Exact UID501 authorization unknown, not assumed root-only. No complete-membership enumeration/bulk-kill contract found.
5. ES alternative explicitly incompatible with constraints: ESTypes.h 267-272 names entitlement, TCC and root requirements/errors; ESMessage.h 1930-1945 auth deadline kills ES CLIENT, not observed subtree, and events can drop. Thus ES deadline is NOT an independent task-tree deadline or Job completion boundary.
6. Public proc_listchildpids/listpgrppids/libproc.h 93-96 are PID enumeration declarations, not complete persistent containment. proc_terminate_all_rsr at133 has no explanatory contract here; cannot infer RSR equals descendant set or permissions. sys/spawn.h 77-86 PControl acts on resource starvation, not wall-clock deadline. Current installed launchd.plist.5 402-407 ExitTimeOut is stop SIGTERM->SIGKILL grace;609-613 cleanup remains PGID only. Auditpipe.4 55-67 device permissions and lossy delivery rule it out as guaranteed complete observation.
