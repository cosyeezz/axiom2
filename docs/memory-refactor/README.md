# 记忆机制分阶段改造

## 文档状态与执行约定

**当前状态：第零阶段实现及范围内专项验收完成（含UI与整理联动）；全仓全量测试与通用UI不宣称全绿，限制见验收记录。原第一至第六阶段暂缓。**

当前实施入口：[第零阶段：用一份可演进的todo记录会话工作](00-evolving-todo.md)。用户最新要求以简单、低维护成本为先，用同一份逐渐丰满的清单表达做过什么、接下来做什么；不引入多层复杂系统。具体联动范围、工具接口与提示词建议见[第零阶段补充：改动清单与提示词草案](00-implementation-and-prompts.md)，旧草案由第零阶段定稿替代。提示词演进见[系统指令与初始化讨论](00-authoring-prompts.md)：最新方向为维护方法统一放系统提示词，不再维护RULES，复用压缩前后提醒；保留程序建文件、缩小初始模板。前轮分拆稿已标记被替代；[最新统一系统提示词](00-system-prompt.md)已定稿并落地。

第零阶段的实际结果以其验收记录为准；原一至六阶段仍是执行草案，不是已实现功能说明。现行机制参见[记忆树整理与查询](../memory-tree-query.md)与[会话记忆方案](../session-memory.md)。本计划基于代码审查和隔离复现，不将现有测试通过等同于缺陷不存在。

用户原要求逐阶段讨论、确认后实施；最新要求先把简化后的理解写成第零阶段，基于文档继续讨论，避免压缩后的语义损失。现已确认第零阶段并授权执行，不直接启动原第一阶段。后续阶段草案不是提前授权，也不是不允许改变的最终设计。

每阶段执行顺序：

1. 读取当前阶段文档，复核最新代码与工作区并行修改。
2. 讨论目标、范围、取舍和验收；将用户意见写入该阶段决策记录。
3. 用户明确确认后，将状态改为“已批准，待实施”。
4. 主代理按步骤修改；适合独立验证的工作可委派，测试期间不修改其覆盖文件。
5. 完成测试与必要文档同步，记录真实结果、未验证项和偏离计划的原因。
6. 向用户交付阶段结果，再讨论下一阶段；不得自动开始下一阶段。

出现范围扩大、需要真实模型、操作真实数据或新增迁移风险时，先补充方案并确认。遇到本阶段授权范围内可修复的测试失败，应继续处理，不以写下“下一步”代替执行。

## 总体目标

以下为原审查路线的目标，需结合第零阶段重新评估。当前优先明确一份可演进todo如何承载计划和简要执行记录，不将原入口形式或阶段划分视为已定案。

- 主入口用自然语言简述目标、关键要求、过程、结果和当前停点；技术细节与证据进入详细文档。
- 全局记忆保留稳定、可辨识的主题，旧内容失效及时，不将旧索引和新正文混作证据。
- 查询只读取解决当前问题所需的内容，默认只向主会话返回可用结论、必要条件和不确定性。
- 浏览、编辑、整理和查询职责清楚，显示范围与授权范围一致。
- 不静默截断事实，不借“优化”删除历史资料，不覆盖其他会话原文或用户自定义规则。

## 已知问题的归属

- 旧贡献在原文变化、物理删除后仍残留：阶段一。
- 查询未比较索引绑定修订、旧条目混合新正文：阶段一。
- 全部直接引用自动展开、无关坏引用导致整体失败：阶段二。
- 无关Item和大段背景进入归纳、答案质量缺少语义评估：阶段二与六。
- 入口长度仅软提示、具体路径过程容易堆积：阶段三。
- 纯自然语言与任务进度、自动接续、自动整理硬耦合：阶段三讨论后定案。
- 既有RULES不随内置规范更新：阶段三。
- 名称空白变体、路径式主题、旧路由过宽、重分类固定前缀：阶段四。
- 单文件失败阻断后续详情、重复提供引用正文：阶段四，读取契约承接阶段二。
- 只读浏览受编辑预算限制、来源难区分、非标准目录文件无入口：阶段五。
- 保存路径在规范化前做目录白名单校验：阶段五中的独立边界修复，可经用户确认单独提前，不以本路线隐含授权。
- 固定Topic目录和全局树的规模开销：阶段四、五、六；不靠关键词硬截取目录掩盖召回损失。

## 全阶段约束

- 本轮实施第零阶段及必要验证，不整理真实记忆；原后续阶段不自动启动。
- 未来实施保留并行修改，禁止整文件回退、替换或夹带无关改动。
- 默认使用临时数据、假模型、随机端口验证；不访问正式浏览器、不重启正式服务，不为测试修改真实模型配置。
- 安装依赖、提交推送、构建共享产物、真实模型调用、真实数据迁移和部署均不由本计划自动授权。
- 已保存原文和逻辑删除会话的记忆保留语义不变；读取失败不等于文件已删除。
- 每阶段完成后更新本阶段结果和必要机制文档；未实现草案不能写入产品文档成为现状。

## 阶段交付模板

每份阶段文档均保留：状态、目标、范围/非目标、实施步骤、验收、风险/恢复、确认记录、实际结果。

实际结果必须包括：修改文件、实际命令和退出码、关键行为证据、未验证项、是否迁移/提交/部署、下一阶段的建议调整。没有执行的命令只标为计划。
