# 前台交互视觉优先

## 原则与边界

- 本地可决定的展示变化先发生，再让浏览器绘制，随后发送后台修改。后台忙不应阻止新会话界面打开、会话从列表消失或置顶图标改变。
- 确认框及未保存内容保护保留。视觉优先不等于绕过删除确认、模型安全切换、认证授权或安装验证。
- 明确拒绝时撤销对应意图，而不是用操作前的整个数组覆盖新快照。其他窗口更新、运行状态和消息计数必须保留。
- 超时、断线属于“结果待确认”，并非确定失败。保留意图并提示，只读 `request.get` 核实，绝不自动重发写操作。`not_found` 不足以判定异步删除未执行：原请求可能仍在停止任务。

## 本次覆盖

| 操作 | 即时展示 | 后台完成与失败 |
| --- | --- | --- |
| 新建会话、快捷键、空工作台模型入口 | 本地“新对话”标题、侧栏占位和可输入文本框 | 真实 ID 返回后接管输入；失败恢复原视图，预备文字仍保存在本窗口；迟到回包不抢导航 |
| 复用当前空会话 | 保持原 Composer 和草稿，按钮立即显示准备状态 | `reuseEmpty` 仍由服务端裁定，不能靠标题断言服务器一定复用 |
| 会话删除 | 确认后关框、隐藏所有列表来源（含置顶和 heldRows）、当前会话立即切到替代项 | 停任务与落库后台完成；拒绝恢复列表，只有没有后续导航时才恢复选中会话 |
| 会话与工作区置顶、改名 | 图标、标题、分组立即更新，改名立即退出编辑 | 意图层撤销即可回退，保留最新服务端其他字段 |
| 工作区移除 | 确认后立即移出列表 | 后台仍检查是否空闲；拒绝恢复，不删除项目文件 |
| 模型收藏 | 星标和排序立即变化 | 拒绝撤销对应收藏意图 |
| 资源保存、安装、移动、移除 | 立即显示提交阶段；已有编辑草稿和确认范围保留 | 真正资源变更仍按后台任务结果确认，不虚报磁盘操作成功 |
| OpenCLI、RTK、REA | 受理前即显示操作提示，不仅禁用按钮 | 后台任务进度接管提示；安装版本、认证结果不得提前假定 |
| 记忆树设置 | 保存中提示，数值失败恢复已保存值 | 保留错误反馈，不让未保存输入看似已生效 |

## 实现入口

- `app/src/client/optimistic-actions.ts`：权威快照外的独立意图覆盖层。
- `app/src/client/transport.ts`：集中覆盖元数据命令、通知跨集合观察者、核实未知回执。
- `app/src/client/workspaces/useWorkspaceView.ts`：窗口导航所有权与代次保护的删除回退。
- `app/src/client/workspaces/useSessionCreation.ts`：本地新建界面；临时 ID 不用于订阅、发送或持久 view。
- `app/src/client/paint-feedback.ts`：先让 React 提交和浏览器绘制，再调度工作；隐藏/暂停窗口有兜底。

## 已检查但不应强行乐观成功的操作

- `TaskSettings`、`MemoryToolbar`、记忆文档保存已有本地草稿、busy 或明确保存状态，不重复引入第二套状态。
- `useConfiguration` 的发布涉及退出认证、执行命令和停止运行确认，必须区分即时编辑草稿与已经发布。
- `ModelPicker` 的草稿选择本来即时；当前模型可能等运行安全点才能切换，不能把运行中的模型身份直接伪装为新模型。
- Fork 已有弹窗即时 busy 和固定 requestId、防迟到导航；创建分支依赖真实历史复制，不把未复制的历史伪装成完整分支。
- 工作区真实鼠标单击的 300ms 是区分双击重命名的手势窗口，不是服务器等待；本次保留，避免破坏双击和移动端侧栏行为。
