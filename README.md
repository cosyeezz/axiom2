# Axiom2

基于 pi 的本地多工作空间 Agent 工作台。已接入运行基础、模型配置／认证以及**独立 pi 主会话执行闭环**；第一阶段仍未全部完成。实施与验收依据：[产品设计](docs/design.md)；设计状态见 [UI 设计同步](docs/ui-sync.md)。文档只描述当前状态，变更轨迹由 Git 保存。

## 当前可用范围

- React 工作台、配置概览、模型服务三个独立页面，沿用设计 CSS、SVG 和响应式布局。
- 本地回环 HTTP/WebSocket 服务、启动链接授权、来源校验、分作用域快照订阅；重连不自动重发操作。
- 通过绝对路径确认和显式授权打开工作空间；创建、切换、搜索、重命名、置顶及删除会话索引。删除不删除项目文件。
- 文本与代码附件草稿按查看实例、工作空间、会话隔离。浏览器 sessionStorage 恢复同标签页草稿，SQLite 保存已确认的草稿副本；尚无跨查看实例的服务端草稿恢复界面。
- 配置概览读取独立 pi 配置目录的供应商／模型数量；可用目录取明确配置与 pi 可用模型的交集，不回传密钥。
- 模型服务读取已发布配置，编辑草稿仅保存在本页内存；顶部保存校验修订冲突、字段与 pi 模型能力后原子替换 models.json。思考等级映射为 pi thinkingLevelMap，请求体数值采样项映射 samplingParams；不支持的协议／字段拒绝保存。
- API Key 保存与单独登录调用 pi 原生接口；OAuth 入口桥接 pi 的授权 URL、设备码、选择与手动输入。认证绑定发起连接，取消、断线或超时终止流程，不自动重新登录；真实供应商与 OAuth 尚未端到端验收。
- 删除模型在顶部保存时确认供应商级退出登录；删除供应商使用独立确认。退出时调用 pi logout，清除受管理密钥、该供应商／模型请求头覆盖和 URL 中的凭据／查询参数，外部环境变量保持不变。环境认证仍有效时如实标记来源，但删除模型不会重现。

- 主会话使用独立 Node.js 工作进程运行 pi；可确认模型／思考等级，发送消息和文本附件，查看真实流式回复、思考内容及工具输入／结果，停止与显式继续。当前运行和后续模型选择分开；每次执行重新加载明确的会话文件，不保留过期空闲运行时。
- 消息、工具与输入独立订阅；Markdown 通过 React 渲染，原始 HTML 不执行、危险链接不生成链接。历史每页 60 条，长输出按需展开。真实 Token、缓存、pi 上下文估算与服务端耗时可展示；没有已知价格时费用为“—”。
- pi JSONL 保留输入与上下文，SQLite 保留执行和受理回执。刷新／重连／服务重启不重发任务；崩溃执行标记中断，未确认清理时禁止续跑。发送前保存浏览器待核实记录，回执不明时可查询而不重发。同一数据目录只允许一个服务管理器。

**未完成：**子 Agent 调度与弹窗、模型收藏／默认子模型、预览评论、Pake 与跨平台验收，完整视觉验收和真实供应商调用验收。双击会话或 F2 可重命名；Delete 弹出删除确认，触屏会话管理待补齐。产品不会生成模拟回复，测试夹具不作为远端供应商验收。

## 启动

需要 Node.js 24+ 与 npm。当前实测 Windows、Node.js 24.19.0、npm 11.17.0；macOS/Linux 尚未实机验收。

```sh
cd app
npm ci
npm run build
npm start
```

打开终端显示的 `http://127.0.0.1:4317/#access=…` 完整访问链接。片段令牌交换为 HttpOnly / SameSite cookie 后从地址栏移除；请勿分享访问链接。服务重启后使用新的启动链接授权。

开发模式：`cd app && npm run dev`。可设置 `AXIOM_PORT`（默认 4317，0 为动态端口）与 `AXIOM_DATA_DIR`（明确指定数据根目录）。页面入口：`/`、`/settings.html`、`/model-config.html`。

默认数据目录：Windows `%APPDATA%/Axiom2`；macOS `~/Library/Application Support/Axiom2`；Linux `$XDG_DATA_HOME/Axiom2` 或 `~/.local/share/Axiom2`。SQLite 位于该目录，配置位于 `pi/`，会话文件位于 `sessions/`；不修改终端 pi 的默认配置。编码工具会按已授权任务修改项目文件，授权的项目扩展／包也可能安装项目依赖。外部修改配置后在模型页点击「重新读取」，服务更新配置概览与可用目录；正在编辑的表单不会被配置事件覆盖。配置目录使用当前用户权限，不承诺磁盘加密或系统密钥库。

## 模型配置边界

- 新增供应商使用稳定的 pi provider ID；内置 ID 只提供连接模板，不自动加入模型。填写模型 ID 后完成行内编辑，再统一保存。保存有效不代表远端密钥有效。
- 已保存密钥、请求头值与敏感 URL 不回传；空密钥保留旧认证，显式勾选清除执行供应商级退出。新增 `!` 命令型密钥／请求头必须在保存时额外确认；单独登录不接受命令型密钥。已有不在表单内的模型字段留在服务端，正常编辑不丢弃；供应商请求体项保存时落实到当前各模型，重新读取显示为模型项。
- 配置编辑入口目前要求普通 JSON；含注释/BOM、损坏配置或重复 ID 时拒绝编辑并保留原文件。单个命令上限 200 KB，配置文件上限 1 MB。任意请求体 JSON 不开放，当前只编辑白名单数值采样字段。
- 配置与 auth.json 不是跨文件事务。部分失败明确报告已写入状态，并要求重新读取后核实；SQLite 只保存请求哈希和脱敏结果，不保存提交密钥。认证期间暂停配置写入。涉及退出登录时先列出受影响的活动主会话，单独确认停止；清理未确认时阻止撤销认证。执行使用受保护的配置快照，结束后删除；配置更新只影响后续执行。
- Windows 未指定工具设置时使用 pi PowerShell，其他平台沿用 pi 默认工具。应用 pi 目录内的资源按 pi 规则加载；项目本地资源默认不信任，需在会话环境中单独授权。上下文隔离不是文件系统沙箱。
- “显式继续”是在原上下文发送一条可见的继续要求，不重放旧请求／工具。pi 正常取消后允许继续；强制终止或服务崩溃不声称外部副作用全部停止，须用户检查并确认清理。

## 检查

```sh
cd app
npm run build
npm test
npm run check:sdk
npx playwright install chromium
npm run check:ui
```

已有浏览器可通过 `AXIOM_TEST_BROWSER` 指定可执行文件路径。截图与几何报告写入 `app/test-results/`，不写入 `ui/`。

已通过：SQLite 归属、授权、幂等、修订冲突、重启与写入失败回滚；HTTP/WebSocket 来源与访问检查、回执查询；配置目录筛选与敏感值不回传；三个页面在设计规定的九个视口无横向溢出；工作空间／会话／草稿切换、刷新、中文组合输入、多选与复制；迟到的新建回执不抢占查看位置，已删除会话重载后清理选中状态，未完成的模型编辑切换前确认；真实配置发布、重新读取、API Key 登录／取消与删除退出；模型保存验证、并发修订冲突、部分失败、敏感值不回传与请求不重做。

`check:sdk` 使用**回环协议测试夹具**验证已安装 pi 的创建会话、API Key 登录／退出、四个独立工具注册、流式／工具事件、会话文件恢复和运行中停止。测试工具不接入产品调度，不代表子 Agent 已实现；`models.test.ts` 另用隔离 OAuth 夹具检查认证桥接、归属和取消，不访问远端。`agent.test.ts` 通过产品工作进程执行 pi 的 write/read/edit／平台命令，检查并发会话、归属、重复受理、停止、恢复、供应商撤销前停止和损坏文件拒绝恢复；可设置 `AXIOM_TEST_COMPILED=1` 检查已构建的服务／工作进程。浏览器还检查实际工具输出、流式期间草稿／选区／模型搜索保持、Markdown 注入防护、停止／继续与刷新不重发。以上模型端均为回环夹具，未验证真实供应商、真实 OAuth。浏览器检查不等于完整 UI-01，子会话及完整视觉对照仍待完成。

## 目录与设计维护

- `ui/`：用户设计源，只读。
- `app/src/`：产品开发代码；`app/tests/`：自动检查。
- `app/` 根目录原有 HTML、图片与检查脚本：保留的原型副本，不是产品运行入口。
- `docs/design.md`：第一阶段目标、架构、接口与验收约束。
- `docs/ui-sync.md`：当前采用提交、同步状态与检查方式。
- 根目录 ZIP：保留的用户交付包，不自动重打包。

设计更新先单独提交，再按 Git 差异移植至 `app/`，不整目录覆盖已接入功能。当前仅使用本地 Git，不创建远端或推送。
